# ChapterJS documentation

The user-facing documentation site of ChapterJS, built on [Mintlify](https://mintlify.com).

- Preview: `npm i -g mint`, then `mint dev` in this folder (the site opens at `http://localhost:3000`).
- Check links: `mint broken-links`.
- Style guide, page templates and terminology: `AGENTS.md`.
- Navigation: `docs.json`. A page not listed there is not published.

The site is deployed from the default branch by the Mintlify GitHub app.
