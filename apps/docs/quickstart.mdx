## Prerequisites

- Node.js 22.18 or newer
- A Discord application with a bot, from the [Developer Portal](https://discord.com/developers/applications)
- A Discord server where you can test your bot

## Get started

<Steps>
  <Step title="Create the project">
    Run the command for your package manager:

    <CodeGroup>
    ```bash pnpm
    pnpm create chapter
    ```

    ```bash npm
    npm create chapter@latest
    ```

    ```bash yarn
    yarn create chapter
    ```

    ```bash bun
    bun create chapter
    ```
    </CodeGroup>

    It asks you up to three questions:

    1. **Where to create the project**: a folder name like `my-bot`, or `.` to use the current folder. The folder must be new or empty.
    2. **Which package manager to use**: only the ones installed on your computer can be picked, and the one you ran the command with is selected by default.
    3. **Which template to start from**.

    A question with only one possible answer is skipped: if you have a single package manager installed, it is used directly, and so is the template while there is only one.

    It then copies the template and installs the dependencies.

    <Tip>
      You can skip the first question by passing the folder name: `pnpm create chapter my-bot`.
    </Tip>

  </Step>
  <Step title="Configure">
    Copy `.env.example` to `.env` and fill in:

    - `BOT_TOKEN`: your bot token, from the **Bot** page of your application.
    - `DEV_GUILD_ID`: the ID of your test server (right-click the server, then **Copy Server ID**).

  </Step>
  <Step title="Run it">
    <CodeGroup>
    ```bash pnpm
    pnpm dev
    ```

    ```bash npm
    npm run dev
    ```

    ```bash yarn
    yarn dev
    ```

    ```bash bun
    bun dev
    ```
    </CodeGroup>

    Your bot connects to your test server. If something is missing (the bot is not in the server yet, an option to enable...), the command tells you what to do and waits for you: see [chapterjs dev](/dev).

  </Step>
  <Step title="Try your first command">
    The default template comes with a command, in `src/commands/ping.ts`:

    ```ts src/commands/ping.ts
    import { command } from 'chapterjs';

    export default command({
      description: 'Replies with Pong!',
      async run({ interaction }) {
        await interaction.reply('Pong!');
      },
    });
    ```

    Type `/ping` in your test server. Then change the answer and save: your bot reloads instantly.

    The path of a file is the name of its command, and a folder in `src/events/` is something your bot reacts to: see [Commands](/commands) and [Events](/events).

  </Step>
</Steps>

When your bot is ready for everyone, put your project on a machine that stays on and run [`chapterjs start`](/start) there.
