---

Discord utilise des nombres pour les sortes, les styles et les niveaux. ChapterJS exporte leurs noms, pour que vous n’écriviez jamais un nombre dont il faut retenir le sens.

<Note>
  Les permissions ne sont pas ici : elles ont [leur propre page](/fr/reference/permissions). Les drapeaux d’un message et d’un utilisateur se lisent par leur nom (`message.flags`, `user.flags`) : voir [Message](/fr/reference/message) et [User](/fr/reference/user).
</Note>

```ts
import { ChannelType, type Guild } from 'chapterjs';

async function createLounge(guild: Guild) {
  return guild.createChannel({ name: 'lounge', type: ChannelType.GuildVoice });
}
```

Chaque énumération est à la fois une valeur et un type : `ChannelType.GuildVoice` vaut `2`, et une variable de type `ChannelType` accepte n’importe laquelle des valeurs.

## ChannelType

La sorte d’un salon : `channel.type`, et le `type` de [`ChannelCreateOptions`](/fr/reference/options#channelcreateoptions) et de [`ThreadCreateOptions`](/fr/reference/options#threadcreateoptions). Les méthodes `is...()` d’un salon répondent à la même question sans nombre : voir [Salons](/fr/reference/channels).

| Nom | Valeur | Signification |
| --- | --- | --- |
| `ChannelType.GuildText` | `0` | Un salon textuel d’un serveur |
| `ChannelType.Dm` | `1` | Une conversation privée entre deux utilisateurs |
| `ChannelType.GuildVoice` | `2` | Un salon vocal d’un serveur |
| `ChannelType.GroupDm` | `3` | Une conversation privée entre plusieurs utilisateurs |
| `ChannelType.GuildCategory` | `4` | Une catégorie, qui regroupe jusqu’à 50 salons |
| `ChannelType.GuildAnnouncement` | `5` | Un salon que d’autres serveurs peuvent suivre (anciennement salons d’actualités) |
| `ChannelType.AnnouncementThread` | `10` | Un fil dans un salon d’annonces |
| `ChannelType.PublicThread` | `11` | Un fil dans un salon textuel, ou une publication d’un forum |
| `ChannelType.PrivateThread` | `12` | Un fil visible seulement par les personnes invitées et les membres avec `ManageThreads` |
| `ChannelType.GuildStageVoice` | `13` | Un salon de conférence, où quelques-uns parlent à un public |
| `ChannelType.GuildDirectory` | `14` | Le salon d’un hub qui liste ses serveurs |
| `ChannelType.GuildForum` | `15` | Un forum : il ne contient que des publications |
| `ChannelType.GuildMedia` | `16` | Un salon média : comme un forum, pour les images et les vidéos |

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#channel-object-channel-types)
