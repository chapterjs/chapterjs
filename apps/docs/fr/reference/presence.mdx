---

`presence()` déclare la présence du bot, une fois, depuis n’importe quel fichier de `src/`. Elle prend un objet, `PresenceConfig`.

```ts src/presence.ts
import { presence } from 'chapterjs';

export default presence({
  status: 'online',
  activity: { type: 'watching', name: 'le serveur' },
});
```

<Note>
  Comment écrire le fichier, et ce qu’affiche Discord pour chaque type, est dans le
  [guide](/fr/presence). Cette page liste ce qui existe.
</Note>

## presence()

```ts
presence(config: PresenceConfig): PresenceDeclaration
```

Déclare la présence du bot : son statut et ce qu’il fait, affichés sous son nom. Exportez le résultat depuis n’importe quel fichier de `src/`, une fois ; le bot l’a dès qu’il est connecté.

### PresenceDeclaration

Ce que renvoie `presence()` : une déclaration que le framework trouve dans les exports d’un fichier.

<ResponseField name="config" type="unknown">
  Ce que le fichier a donné à `presence()`, pas encore vérifié.
</ResponseField>

## PresenceConfig

```ts
type PresenceConfig = SinglePresenceConfig | RotatingPresenceConfig;
```

Ce qu’un fichier donne à `presence()` : `activity` pour une seule, ou `activities` pour plusieurs affichées tour à tour.

### SinglePresenceConfig

Une présence avec une activité, ou aucune.

<ResponseField name="status" type="PresenceStatusName">
  Le statut du bot. `'online'` par défaut.
</ResponseField>

<ResponseField name="activity" type="Activity">
  Ce que fait le bot. Rien par défaut.
</ResponseField>

### RotatingPresenceConfig

Une présence dont les activités s’affichent tour à tour.

<ResponseField name="status" type="PresenceStatusName">
  Le statut du bot. `'online'` par défaut.
</ResponseField>

<ResponseField name="activities" type="Activities" required>
  Plusieurs activités, affichées l’une après l’autre, chacune pendant son
  `for` : une liste, ou une fonction qui la donne.
</ResponseField>

### PresenceStatusName

```ts
type PresenceStatusName = 'online' | 'idle' | 'dnd' | 'invisible';
```

Le statut du bot : `'online'` (vert), `'idle'` (orange), `'dnd'` (rouge, « ne pas déranger ») ou `'invisible'` (affiché hors ligne).

## Activities

```ts
type Activities =
  | readonly Activity[]
  | ((context: PresenceContext) => readonly Activity[] | Promise<readonly Activity[]>);
```

Les activités affichées tour à tour : une liste, ou une fonction qui la donne (éventuellement après une promesse, depuis un store par exemple), exécutée de nouveau chaque fois que la liste a été affichée en entier.

## Activity

Ce que fait le bot : une `PlainActivity` ou une `StreamingActivity`.

### PlainActivity

Une activité qui n’est pas un stream.

<ResponseField name="type" type="ActivityKind" required>
  Ce que fait le bot, comme l’affiche Discord : « Joue à _name_ », « Écoute
  _name_ », « Regarde _name_ », « Participe à _name_ », ou le texte lui-même avec
  `'custom'`.
</ResponseField>

<ResponseField name="name" type="ActivityText" required>
  Ce qui est affiché après le type (ou seul avec `'custom'`).
</ResponseField>

<ResponseField name="for" type="Duration">
  Combien de temps l’activité s’affiche avant la suivante, 5 secondes au
  minimum : `'30s'`, `'2m'`. 30 secondes par défaut. Seule, c’est la fréquence
  à laquelle un `name` qui est une fonction s’exécute de nouveau.
</ResponseField>

### ActivityKind

```ts
type ActivityKind =
  'playing' | 'listening' | 'watching' | 'competing' | 'custom';
```

### StreamingActivity

Un stream : « Streame _name_ », avec un lien vers lui.

<ResponseField name="type" type="'streaming'" required></ResponseField>

<ResponseField name="name" type="ActivityText" required>
  Ce qui est affiché après « Streame ».
</ResponseField>

<ResponseField name="url" type="string" required>
  Le stream : Discord n’accepte qu’un lien `https://twitch.tv/` ou
  `https://youtube.com/`.
</ResponseField>

<ResponseField name="for" type="Duration">
  Combien de temps l’activité s’affiche avant la suivante, 5 secondes au
  minimum : `'30s'`, `'2m'`. 30 secondes par défaut. Seule, c’est la fréquence
  à laquelle un `name` qui est une fonction s’exécute de nouveau.
</ResponseField>

### ActivityText

```ts
type ActivityText =
  string | ((context: PresenceContext) => string | Promise<string>);
```

Le texte d’une activité : un texte, ou une fonction qui le donne (éventuellement après une promesse), exécutée chaque fois que l’activité s’affiche.

## PresenceContext

Ce que reçoit une fonction de la présence, à chaque exécution : le nombre de serveurs où est le bot, et les textes des fichiers de langue dans la langue par défaut.

<ResponseField name="guilds" type="number" required>
  Le nombre de serveurs où est le bot, tous processus confondus.
</ResponseField>

<ResponseField name="t" type="Translator">
  Les textes des fichiers de langue, dans la langue par défaut. Seulement quand
  le projet a des fichiers de langue.
</ResponseField>
