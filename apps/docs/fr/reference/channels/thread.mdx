Un `ThreadChannel` est un fil, ou une publication d’un forum. C’est ce que donne `channel.isThread()`, et ce que renvoient `message.startThread()`, `channel.startThread()` et `forum.createPost()`.

```ts
import type { ThreadChannel } from 'chapterjs';

async function close(thread: ThreadChannel, reason: string) {
  if (thread.archived) return;
  await thread.send(`Je ferme ce fil : ${reason}`);
  await thread.edit({ archived: true, locked: true }, reason);
}
```

<Note>
  Comment envoyer, modifier et lire des messages est dans [Envoyer des messages](/fr/messages).
</Note>

## Propriétés

Il a aussi tout ce qu’a [Channel](/fr/reference/channels#channel) et [ce que partagent les salons avec des messages](/fr/reference/channels#salons-avec-des-messages). Un fil n’est pas un `GuildChannel` : il n’a pas de remplacements de permissions à lui, et prend les permissions du salon où il se trouve.

## Helpers

### permissionsFor()

```ts
permissionsFor(member: GuildMember): Permissions
```

Les fils héritent des permissions du salon où ils se trouvent.

## Lire depuis Discord

### fetchMembers()

```ts
fetchMembers(options?: { limit?: number; after?: Snowflake }): Promise<ThreadMember[]>
```

Qui est dans le fil (100 au plus par appel). Chaque entrée est un [`ThreadMember`](/fr/reference/data#threadmember).

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#list-thread-members)

## Actions

### edit()

```ts
edit(options: ThreadEditOptions, reason?: string): Promise<this>
```

Modifie le fil : nom, archive, verrou, mode lent, étiquettes. Les options sont un [`ThreadEditOptions`](/fr/reference/options#threadeditoptions).

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#modify-channel)

### archive()

```ts
archive(reason?: string): Promise<this>
```

Archive le fil : il quitte la liste des salons mais peut revenir.

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#modify-channel)

### unarchive()

```ts
unarchive(reason?: string): Promise<this>
```

Fait revenir un fil archivé.

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#modify-channel)

### join()

```ts
join(): Promise<void>
```

Fait rejoindre le fil au bot.

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#join-thread)

### leave()

```ts
leave(): Promise<void>
```

Fait quitter le fil au bot.

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#leave-thread)

### addMember()

```ts
addMember(user: Snowflake | { id: Snowflake }): Promise<void>
```

Ajoute un membre au fil.

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#add-thread-member)

### removeMember()

```ts
removeMember(user: Snowflake | { id: Snowflake }): Promise<void>
```

Retire un membre du fil.

[Documentation de Discord](https://docs.discord.com/developers/resources/channel#remove-thread-member)
