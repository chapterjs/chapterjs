---
title: 'Message'
description: 'A message sent in a channel: what it contains, and how to reply, edit, react, pin and start a thread from it'
---

A `Message` is a message sent in a channel. You get one from the [events about messages](/events/messages), from what `send()` and `reply()` return, and from `fetchMessage()` and `fetchMessages()` on a channel.

```ts
import type { Message } from 'chapterjs';

async function onPing(message: Message) {
  if (!message.isFromUser) return; // ignore bots, webhooks and system messages
  if (message.content !== '!ping') return;

  const reply = await message.reply('Pong!');
  await reply.react('🏓');
}
```

<Note>
  How to send, edit and read messages is in [Sending messages](/messages); everything `reply()` and `edit()` accept is in [Message options](/reference/message-options).
</Note>

<Warning>
  `content`, `embeds` and `attachments` are empty for the messages of other people unless the **Message Content Intent** is enabled for your bot. Messages that mention the bot, and private messages, always have their content.
</Warning>

<ResponseField name="channel" type="TextBasedChannel | null">

<ResponseField name="member" type="GuildMember | null">

</ResponseField>

<ResponseField name="type" type="MessageType">

<ResponseField name="editedAt" type="Date | null">
  When the message was last edited; `null` when it never was.
</ResponseField>

<ResponseField name="pinned" type="boolean">
  Whether the message is pinned.
</ResponseField>

<ResponseField name="tts" type="boolean">
  Whether the message was read aloud.
</ResponseField>

<ResponseField name="embeds" type="Embed[]">
  The embeds of the message. Each entry is an [`Embed`](/reference/message-options#embed).
</ResponseField>

<ResponseField name="attachments" type="Attachment[]">
  The files attached to the message. Each entry is an [`Attachment`](/reference/data#attachment).
</ResponseField>

<ResponseField name="reactions" type="Reaction[]">
  The reactions on the message, one entry per emoji. Each entry is a [`Reaction`](/reference/data#reaction).
</ResponseField>

<ResponseField name="mentionsEveryone" type="boolean">
  Whether the message mentions @everyone or @here.
</ResponseField>

<ResponseField name="mentionedRoleIds" type="readonly Snowflake[]">
  The ids of the roles mentioned in the message.
</ResponseField>

<ResponseField name="flags" type="MessageFlagName[]">
  The flags of the message, by name (`Ephemeral`, `SuppressEmbeds`...).
</ResponseField>

<ResponseField name="webhookId" type="Snowflake | null">
  The id of the webhook that sent the message, when one did.
</ResponseField>

<ResponseField name="repliedMessageId" type="Snowflake | null">
  The id of the message this one replies to, when it is a reply.
</ResponseField>

<ResponseField name="isFromUser" type="boolean">
  Whether a person wrote it: not a bot, a webhook or Discord itself.
</ResponseField>

<ResponseField name="url" type="string">
  The link that opens the message in Discord.
</ResponseField>

## Helpers

These read what the bot already knows: they never send a request.

```ts
toJSON(): object
```

## Reading from Discord

### fetch()

```ts
fetch(): Promise<Message>
```

Asks Discord for the latest version of the message.

[Discord documentation](https://docs.discord.com/developers/resources/message#get-channel-message)

### fetchReactionUsers()

```ts
fetchReactionUsers(emoji: EmojiInput, options?: { limit?: number; after?: Snowflake }): Promise<User[]>
```

The users who reacted with an emoji (100 at most per call).

[Discord documentation](https://docs.discord.com/developers/resources/message#get-reactions)

## Actions

### reply()

```ts
reply(message: MessageInput): Promise<Message>
```

Answers the message, in the same channel. What it accepts is a [`MessageInput`](/reference/message-options#messageinput).

[Discord documentation](https://docs.discord.com/developers/resources/message#create-message)

### edit()

```ts
edit(message: string | MessageEditOptions): Promise<Message>
```

Changes the message. Only the content, embeds, components and files of a message the bot wrote can change. The options are a [`MessageEditOptions`](/reference/message-options#messageeditoptions).

[Discord documentation](https://docs.discord.com/developers/resources/message#edit-message)

### delete()

```ts
delete(reason?: string): Promise<void>
```

Deletes the message.

[Discord documentation](https://docs.discord.com/developers/resources/message#delete-message)

### react()

```ts
react(emoji: EmojiInput): Promise<void>
```

Adds a reaction of the bot to the message.

[Discord documentation](https://docs.discord.com/developers/resources/message#create-reaction)

### removeReaction()

```ts
removeReaction(emoji: EmojiInput, user?: Snowflake | { id: Snowflake }): Promise<void>
```

Removes a reaction: of the bot, or of the given user.

[Discord documentation](https://docs.discord.com/developers/resources/message#delete-user-reaction)

### clearReactions()

```ts
clearReactions(emoji?: EmojiInput): Promise<void>
```

Removes every reaction of the message, or every reaction of one emoji.

[Discord documentation](https://docs.discord.com/developers/resources/message#delete-all-reactions)

### pin()

```ts
pin(reason?: string): Promise<void>
```

Pins the message in its channel.

[Discord documentation](https://docs.discord.com/developers/resources/message#pin-message)

### unpin()

```ts
unpin(reason?: string): Promise<void>
```

Unpins the message.

[Discord documentation](https://docs.discord.com/developers/resources/message#unpin-message)

### crosspost()

```ts
crosspost(): Promise<Message>
```

Publishes a message of an announcement channel to the servers that follow it.

[Discord documentation](https://docs.discord.com/developers/resources/message#crosspost-message)

### startThread()

```ts
startThread(
  options: { name: string; autoArchiveDuration?: number; rateLimitPerUser?: number | null },
  reason?: string
): Promise<ThreadChannel>
```

Starts a thread from the message.

<ResponseField name="name" type="string" required>
  The name of the thread, 1 to 100 characters.
</ResponseField>

<ResponseField name="autoArchiveDuration" type="number">
  After how many minutes without activity the thread leaves the channel list: 60, 1440, 4320 or 10080.
</ResponseField>

<ResponseField name="rateLimitPerUser" type="number | null">
  How many seconds a member waits between two messages (0 to 21600).
</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/channel#start-thread-from-message)

## Types

### GuildMessage

A message of a server: its server is known. It is what the events about messages give for what happens in a server.

<ResponseField name="guildId" type="Snowflake">
  The id of the server.
</ResponseField>

<ResponseField name="guild" type="Guild">
  The server of the message.
</ResponseField>

<ResponseField name="channel" type="GuildTextBasedChannel">
  The channel of the message.
</ResponseField>

### MemberMessage

A message written in a server by one of its members: neither a private message nor the message of a webhook. It is what the events about messages give by default. It has everything of `GuildMessage`, and:

<ResponseField name="member" type="GuildMember">
  The author as a member of the server.
</ResponseField>

### PrivateMessage

A private message, for a file that receives both kinds (`{ where: 'both' }`): there is no server, which is how it is told apart from a `GuildMessage`.

<ResponseField name="guildId" type="null">
  No server: it is a private message.
</ResponseField>

<ResponseField name="guild" type="null">
  No server: it is a private message.
</ResponseField>

<ResponseField name="member" type="null">
  No member: the author is `author`.
</ResponseField>

<ResponseField name="channel" type="DMChannel | null">
  The private conversation, when the bot knows it.
</ResponseField>

### DmMessage

A private message, for a file that only receives those (`{ where: 'dm' }`): nothing about a server exists on it. `guildId`, `guild` and `member` are not even offered by your editor.

<ResponseField name="channel" type="DMChannel | null">
  The private conversation, when the bot knows it.
</ResponseField>

You only need these names to type a function of your own:

```ts
import type { MemberMessage } from 'chapterjs';

export function xpFor(message: MemberMessage): number {
  return message.member.roles.length + message.content.length;
}
```

### EmojiInput

```ts
type EmojiInput = string | { id?: Snowflake | null; name?: string | null }
```

An emoji to react with: a standard one (`"👍"`), or a custom one. The methods that take one accept:

- a standard emoji: `'👍'`
- a custom emoji as Discord writes it: `'<:name:123456789012345678>'` (or `'<a:name:…>'` when animated)
- a custom emoji as an object: `{ id: '123456789012345678', name: 'name' }`, or a [`GuildEmoji`](/reference/emoji)

An empty text is refused before anything is sent:

```text
The emoji is empty: pass one like "👍".
```

### MessageFlagName

```ts
type MessageFlagName = keyof typeof MessageFlags
```

The name of a flag of a message: a key of [`MessageFlags`](/reference/enums#messageflags). It is what `flags` lists.
