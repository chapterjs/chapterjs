---
title: 'Values'
description: 'The named values Discord uses: channel types, message types, styles, levels'
---

Discord uses numbers for kinds, styles and levels. ChapterJS exports their names, so you never write a number whose meaning you have to remember:

```ts
import { ChannelType, type Guild } from 'chapterjs';

async function createVoice(guild: Guild) {
  return guild.createChannel({ name: 'Lounge', type: ChannelType.GuildVoice });
}
```

Each of these is both a value and a type: `ChannelType.GuildText` is `0`, and a variable of type `ChannelType` accepts any of the values.
