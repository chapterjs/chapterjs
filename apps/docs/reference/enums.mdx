Discord uses numbers for kinds, styles and levels. ChapterJS exports their names, so you never write a number whose meaning you have to remember.

<Note>
  Permissions are not here: they have [their own page](/reference/permissions). The flags of a message and of a user are read by name (`message.flags`, `user.flags`): see [Message](/reference/message) and [User](/reference/user).
</Note>

```ts
import { ChannelType, type Guild } from 'chapterjs';

async function createLounge(guild: Guild) {
  return guild.createChannel({ name: 'lounge', type: ChannelType.GuildVoice });
}
```

Each enum is both a value and a type: `ChannelType.GuildVoice` is `2`, and a variable of type `ChannelType` accepts any of the values.

## ChannelType

The kind of a channel: `channel.type`, and the `type` of [`ChannelCreateOptions`](/reference/options#channelcreateoptions) and [`ThreadCreateOptions`](/reference/options#threadcreateoptions). The `is...()` methods of a channel answer the same question without a number: see [Channels](/reference/channels).

| Name | Value | Meaning |
| --- | --- | --- |
| `ChannelType.GuildText` | `0` | A text channel of a server |
| `ChannelType.Dm` | `1` | A private conversation between two users |
| `ChannelType.GuildVoice` | `2` | A voice channel of a server |
| `ChannelType.GroupDm` | `3` | A private conversation between several users |
| `ChannelType.GuildCategory` | `4` | A category, which groups up to 50 channels |
| `ChannelType.GuildAnnouncement` | `5` | A channel other servers can follow (formerly news channels) |
| `ChannelType.AnnouncementThread` | `10` | A thread in an announcement channel |
| `ChannelType.PublicThread` | `11` | A thread in a text channel, or a post of a forum |
| `ChannelType.PrivateThread` | `12` | A thread only visible to those invited and to members with `ManageThreads` |
| `ChannelType.GuildStageVoice` | `13` | A stage channel, where a few speak to an audience |
| `ChannelType.GuildDirectory` | `14` | The channel of a hub that lists its servers |
| `ChannelType.GuildForum` | `15` | A forum: it only contains posts |
| `ChannelType.GuildMedia` | `16` | A media channel: like a forum, for images and videos |

[Discord documentation](https://docs.discord.com/developers/resources/channel#channel-object-channel-types)
