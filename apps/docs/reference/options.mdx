The methods that create or change something take an options object. Its fields are the ones of Discord, written in camelCase; your editor completes them.

<Note>
  These options belong to the actions of [Guild](/reference/guild), the [channels](/reference/channels) and [Role](/reference/role). What a message takes is in [Message options](/reference/message-options), what a member takes in [GuildMember](/reference/member#types).
</Note>

A few rules hold everywhere:

- When editing, only what you pass changes. `null` removes a value where the type allows it.
- Images are data URIs: `data:image/png;base64,...`.
- Ids are `Snowflake`s: the `id` of a structure, or the text copied from Discord.
- Permissions are written by name (`'ManageThreads'`), never as numbers: see [Permissions](/reference/permissions).

```ts
import type { Guild } from 'chapterjs';

async function setUp(guild: Guild) {
  const role = await guild.createRole({ name: 'Helper', permissions: ['ManageMessages'] });
  await guild.createChannel({ name: 'help', topic: `Ask ${role} anything` });
}
```

## GuildEditOptions

What `edit()` takes on a server: only what is passed changes. Images are data URIs (`data:image/png;base64,...`).

```ts
guild.edit(options: GuildEditOptions, reason?: string): Promise<Guild>
```

<ResponseField name="name" type="string">The name of the server.</ResponseField>
<ResponseField name="verificationLevel" type="VerificationLevel | null">What Discord asks of new members before they can write: a value of [`VerificationLevel`](/reference/enums#verificationlevel).</ResponseField>
<ResponseField name="defaultMessageNotifications" type="DefaultMessageNotificationLevel | null">Whether members get a notification for every message or only when they are mentioned, by default: a value of [`DefaultMessageNotificationLevel`](/reference/enums#defaultmessagenotificationlevel).</ResponseField>
<ResponseField name="explicitContentFilter" type="ExplicitContentFilterLevel | null">Whose images and videos Discord scans for explicit content: a value of [`ExplicitContentFilterLevel`](/reference/enums#explicitcontentfilterlevel).</ResponseField>
<ResponseField name="afkChannelId" type="Snowflake | null">The id of the voice channel inactive members are moved to.</ResponseField>
<ResponseField name="afkTimeout" type="number">After how many seconds of inactivity a member is moved there: `60`, `300`, `900`, `1800` or `3600`.</ResponseField>
<ResponseField name="icon" type="string | null">The icon: a 1024x1024 PNG, JPEG or GIF (an animated GIF only when the server has the `ANIMATED_ICON` feature).</ResponseField>
<ResponseField name="splash" type="string | null">The background of the invite page: a 16:9 PNG or JPEG (when the server has the `INVITE_SPLASH` feature).</ResponseField>
<ResponseField name="discoverySplash" type="string | null">The background shown in server discovery: a 16:9 PNG or JPEG (when the server has the `DISCOVERABLE` feature).</ResponseField>
<ResponseField name="banner" type="string | null">The banner: a 16:9 PNG or JPEG (when the server has the `BANNER` feature; an animated GIF when it has the `ANIMATED_BANNER` feature).</ResponseField>
<ResponseField name="systemChannelId" type="Snowflake | null">The id of the channel where Discord posts welcome messages and boost notices.</ResponseField>
<ResponseField name="systemChannelFlags" type="number">Which of those notices are hidden, as a bit field.</ResponseField>
<ResponseField name="rulesChannelId" type="Snowflake | null">The id of the channel that shows the rules, in a community server.</ResponseField>
<ResponseField name="publicUpdatesChannelId" type="Snowflake | null">The id of the channel where the admins and moderators of a community server receive notices from Discord.</ResponseField>
<ResponseField name="preferredLocale" type="Locale | null">The language of a community server, used in server discovery and in the notices Discord sends; `'en-US'` by default. A value of [`Locale`](/reference/enums#locale).</ResponseField>
<ResponseField name="features" type="GuildFeature[]">The features enabled on the server: see [`GuildFeature`](/reference/guild#types).</ResponseField>
<ResponseField name="description" type="string | null">The description of the server.</ResponseField>
<ResponseField name="premiumProgressBarEnabled" type="boolean">Whether the boost progress bar is shown.</ResponseField>
<ResponseField name="safetyAlertsChannelId" type="Snowflake | null">The id of the channel where the admins and moderators of a community server receive safety alerts from Discord.</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/guild#modify-guild-json-params)

## ChannelCreateOptions

What `createChannel()` takes: a name, a type, and the settings of that kind of channel.

```ts
guild.createChannel(options: ChannelCreateOptions, reason?: string): Promise<GuildChannel>
```

Only `name` is needed: without a `type`, Discord creates a text channel. The other fields only apply to the kind of channel they describe.

<ResponseField name="name" type="string" required>The name of the channel (1-100 characters).</ResponseField>
<ResponseField name="type" type="ChannelType | null">The kind of channel: a value of [`ChannelType`](/reference/enums#channeltype).</ResponseField>
<ResponseField name="topic" type="string | null">The topic shown at the top of the channel (0-1024 characters).</ResponseField>
<ResponseField name="bitrate" type="number | null">The audio quality of a voice or stage channel, in bits per second; 8000 at least.</ResponseField>
<ResponseField name="userLimit" type="number | null">How many people can join a voice channel.</ResponseField>
<ResponseField name="rateLimitPerUser" type="number | null">Slowmode: how many seconds a member waits between two messages (0-21600). Bots and members with the `BypassSlowmode` permission are not affected.</ResponseField>
<ResponseField name="position" type="number | null">Where the channel is in the list (channels with the same position are sorted by id).</ResponseField>
<ResponseField name="permissionOverwrites" type="object[] | null">
  What roles and members are allowed or denied in the channel.
  <Expandable title="fields of an overwrite">
    <ResponseField name="id" type="Snowflake">The id of the role or of the member.</ResponseField>
    <ResponseField name="type" type="0 | 1">`0` for a role, `1` for a member.</ResponseField>
    <ResponseField name="allow" type="string">What is allowed, as the text Discord expects: `new Permissions(['SendMessages']).toString()`.</ResponseField>
    <ResponseField name="deny" type="string">What is denied, written the same way.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="parentId" type="Snowflake | null">The id of the category to put the channel in.</ResponseField>
<ResponseField name="nsfw" type="boolean | null">Whether the channel is age-restricted.</ResponseField>
<ResponseField name="rtcRegion" type="string | null">The voice region of a voice or stage channel; `null` lets Discord pick it.</ResponseField>
<ResponseField name="videoQualityMode" type="VideoQualityMode | null">The camera quality of a voice channel: a value of [`VideoQualityMode`](/reference/enums#videoqualitymode).</ResponseField>
<ResponseField name="defaultAutoArchiveDuration" type="number | null">After how many minutes without activity the Discord app suggests archiving a new thread of the channel.</ResponseField>
<ResponseField name="defaultReactionEmoji" type="object | null">
  The emoji of the "add reaction" button on the posts of a forum or media channel.
  <Expandable title="fields">
    <ResponseField name="emojiId" type="Snowflake | null">The id of a custom emoji of the server.</ResponseField>
    <ResponseField name="emojiName" type="string | null">A standard emoji, as its character.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="availableTags" type="ForumTag[] | null">The tags the posts of a forum or media channel can have: see [`ForumTag`](/reference/data#forumtag).</ResponseField>
<ResponseField name="defaultSortOrder" type="ForumSortOrderType | null">How the posts of a forum or media channel are ordered: a value of [`ForumSortOrderType`](/reference/enums#forumsortordertype).</ResponseField>
<ResponseField name="defaultForumLayout" type="ForumLayoutType | null">How the posts of a forum are displayed: a value of [`ForumLayoutType`](/reference/enums#forumlayouttype).</ResponseField>
<ResponseField name="defaultThreadRateLimitPerUser" type="number | null">The slowmode given to new threads of the channel. It is copied when the thread is created and does not follow later changes.</ResponseField>
<ResponseField name="flags" type="number | null">The flags of the channel, as a bit field.</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/guild#create-guild-channel-json-params)

## GuildChannelEditOptions

What `edit()` takes on a channel of a server.

```ts
channel.edit(options: GuildChannelEditOptions, reason?: string): Promise<this>
```

It works on every channel of a server that is not a thread: text, voice, category and forum channels. A field that does not apply to the kind of channel is refused by Discord.

<ResponseField name="name" type="string">The name of the channel (1-100 characters).</ResponseField>
<ResponseField name="type" type="ChannelType">The kind of channel: a value of [`ChannelType`](/reference/enums#channeltype). Only a text channel can become an announcement channel and back, in a server that has the `NEWS` feature.</ResponseField>
<ResponseField name="position" type="number | null">Where the channel is in the list (channels with the same position are sorted by id).</ResponseField>
<ResponseField name="topic" type="string | null">The topic shown at the top of the channel: 0-1024 characters, or 0-4096 for a forum or media channel.</ResponseField>
<ResponseField name="nsfw" type="boolean | null">Whether the channel is age-restricted.</ResponseField>
<ResponseField name="rateLimitPerUser" type="number | null">Slowmode: how many seconds a member waits between two messages (0-21600). Bots and members with the `BypassSlowmode` permission are not affected.</ResponseField>
<ResponseField name="bitrate" type="number | null">The audio quality of a voice or stage channel, in bits per second; 8000 at least.</ResponseField>
<ResponseField name="userLimit" type="number | null">How many people can join: up to 99 in a voice channel, 10,000 in a stage channel; `0` means no limit.</ResponseField>
<ResponseField name="permissionOverwrites" type="object[] | null">What roles and members are allowed or denied in the channel or the category: the same objects as in [`ChannelCreateOptions`](#channelcreateoptions).</ResponseField>
<ResponseField name="parentId" type="Snowflake | null">The id of the category to move the channel to.</ResponseField>
<ResponseField name="rtcRegion" type="string | null">The voice region of the channel; `null` lets Discord pick it.</ResponseField>
<ResponseField name="videoQualityMode" type="VideoQualityMode | null">The camera quality of a voice channel: a value of [`VideoQualityMode`](/reference/enums#videoqualitymode).</ResponseField>
<ResponseField name="defaultAutoArchiveDuration" type="number | null">After how many minutes without activity the Discord app suggests archiving a new thread of the channel.</ResponseField>
<ResponseField name="flags" type="number">The flags of the channel, as a bit field.</ResponseField>
<ResponseField name="availableTags" type="ForumTag[]">The tags the posts of a forum or media channel can have, 20 at most: see [`ForumTag`](/reference/data#forumtag).</ResponseField>
<ResponseField name="defaultReactionEmoji" type="object | null">The emoji of the "add reaction" button on the posts of a forum or media channel: `{ emojiId, emojiName }`, as in [`ChannelCreateOptions`](#channelcreateoptions).</ResponseField>
<ResponseField name="defaultThreadRateLimitPerUser" type="number">The slowmode given to new threads of the channel. It is copied when the thread is created and does not follow later changes.</ResponseField>
<ResponseField name="defaultSortOrder" type="ForumSortOrderType | null">How the posts of a forum or media channel are ordered: a value of [`ForumSortOrderType`](/reference/enums#forumsortordertype).</ResponseField>
<ResponseField name="defaultForumLayout" type="ForumLayoutType">How the posts of a forum are displayed: a value of [`ForumLayoutType`](/reference/enums#forumlayouttype).</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/channel#modify-channel-json-params-guild-channel)

## ThreadCreateOptions

What `startThread()` takes on a text channel.

```ts
textChannel.startThread(options: ThreadCreateOptions, reason?: string): Promise<ThreadChannel>
```

To start a thread from a message, use `message.startThread()` instead: see [Message](/reference/message).

<ResponseField name="name" type="string" required>The name of the thread (1-100 characters).</ResponseField>
<ResponseField name="autoArchiveDuration" type="number">After how many minutes without activity the thread leaves the channel list: `60`, `1440`, `4320` or `10080`.</ResponseField>
<ResponseField name="type" type="ChannelType">The kind of thread: `ChannelType.PublicThread`, `ChannelType.PrivateThread` or `ChannelType.AnnouncementThread` (see [`ChannelType`](/reference/enums#channeltype)).</ResponseField>
<ResponseField name="invitable" type="boolean">Whether members who are not moderators can add other members to the thread. Only for a private thread.</ResponseField>
<ResponseField name="rateLimitPerUser" type="number | null">Slowmode: how many seconds a member waits between two messages (0-21600).</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/channel#start-thread-without-message-json-params)

## ThreadEditOptions

What `edit()` takes on a thread.

```ts
thread.edit(options: ThreadEditOptions, reason?: string): Promise<this>
```

`thread.archive()` and `thread.unarchive()` are shortcuts for `{ archived: true }` and `{ archived: false }`.

<ResponseField name="name" type="string">The name of the thread (1-100 characters).</ResponseField>
<ResponseField name="archived" type="boolean">Whether the thread is archived.</ResponseField>
<ResponseField name="autoArchiveDuration" type="number">After how many minutes without activity the thread leaves the channel list: `60`, `1440`, `4320` or `10080`.</ResponseField>
<ResponseField name="locked" type="boolean">Whether the thread is locked: only members with the `ManageThreads` permission can then unarchive it.</ResponseField>
<ResponseField name="invitable" type="boolean">Whether members who are not moderators can add other members to the thread. Only for a private thread.</ResponseField>
<ResponseField name="rateLimitPerUser" type="number | null">Slowmode: how many seconds a member waits between two messages (0-21600). Bots and members with the `BypassSlowmode` permission are not affected.</ResponseField>
<ResponseField name="flags" type="number">The flags of the thread, as a bit field. Only a post of a forum or media channel can be pinned this way.</ResponseField>
<ResponseField name="appliedTags" type="Snowflake[]">The ids of the tags of a post of a forum or media channel, 5 at most.</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/channel#modify-channel-json-params-thread)

## ForumPostOptions

What `createPost()` takes.

```ts
forum.createPost(options: ForumPostOptions, reason?: string): Promise<ThreadChannel>
```

<ResponseField name="name" type="string" required>The title of the post.</ResponseField>
<ResponseField name="message" type="MessageInput" required>The first message of the post: a text, or everything a message can contain (see [`MessageInput`](/reference/message-options#messageinput)).</ResponseField>
<ResponseField name="appliedTags" type="Snowflake[]">The ids of the tags of the post.</ResponseField>
<ResponseField name="autoArchiveDuration" type="60 | 1440 | 4320 | 10080">After how many minutes without activity the post is archived.</ResponseField>
<ResponseField name="slowmode" type="number">Slowmode of the post, in seconds.</ResponseField>

The message is checked like any other before it is sent: see [Message options](/reference/message-options).

## RoleCreateOptions

What `createRole()` takes. Permissions are given by name, as a list of names or as a `Permissions` set.

```ts
guild.createRole(options?: RoleCreateOptions, reason?: string): Promise<Role>
```

Every field can be left out: `guild.createRole()` creates a role with the defaults of Discord.

<ResponseField name="name" type="string">The name of the role, 100 characters at most.</ResponseField>
<ResponseField name="permissions" type="PermissionResolvable | string">What the role allows: a name, a list of names, a `Permissions` set, or the text Discord uses. See [`PermissionResolvable`](/reference/permissions#permissionresolvable).</ResponseField>
<ResponseField name="colors" type="object">
  The colors of the role.
  <Expandable title="fields">
    <ResponseField name="primaryColor" type="number" required>The main color, as a number (`0xff0000` for red).</ResponseField>
    <ResponseField name="secondaryColor" type="number | null" required>A second color: the role is then shown as a gradient between the two.</ResponseField>
    <ResponseField name="tertiaryColor" type="number | null" required>A third color: the gradient then becomes holographic.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="hoist" type="boolean">Whether members with the role are shown apart in the member list.</ResponseField>
<ResponseField name="icon" type="string | null">The icon of the role, as a data URI (when the server has the `ROLE_ICONS` feature).</ResponseField>
<ResponseField name="unicodeEmoji" type="string | null">A standard emoji shown as the icon of the role (when the server has the `ROLE_ICONS` feature).</ResponseField>
<ResponseField name="mentionable" type="boolean">Whether everyone can mention the role.</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/guild#create-guild-role-json-params)


<ResponseField name="mentionable" type="boolean">Whether everyone can mention the role.</ResponseField>

## InviteCreateOptions

What `createInvite()` takes.

```ts
channel.createInvite(options?: InviteCreateOptions, reason?: string): Promise<Invite>
```

Every field can be left out: `channel.createInvite()` creates an invite with the defaults of Discord.

<ResponseField name="maxAge" type="number">After how many seconds the invite expires, from 0 (never) to 604800 (7 days).</ResponseField>
<ResponseField name="maxUses" type="number">How many times it can be used, from 0 (no limit) to 100.</ResponseField>
<ResponseField name="temporary" type="boolean">Whether the invite only grants a temporary membership: members who join with it are kicked when they go offline.</ResponseField>
<ResponseField name="unique" type="boolean">`true` to always create a new link, instead of reusing a similar one that already exists. Useful for many one-time links.</ResponseField>
<ResponseField name="targetType" type="1 | 2">What a voice channel invite opens: `1` a stream, `2` an embedded activity.</ResponseField>
<ResponseField name="targetUserId" type="Snowflake">The id of the user whose stream to show. Needed when `targetType` is `1`; the user must be streaming in the channel.</ResponseField>
<ResponseField name="targetApplicationId" type="Snowflake">The id of the activity to open. Needed when `targetType` is `2`; the application must have the `EMBEDDED` flag.</ResponseField>
<ResponseField name="targetUserIds" type="Snowflake[]">The ids of the only users who can see and accept the invite, 1000 at most.</ResponseField>
<ResponseField name="roleIds" type="Snowflake[]">The ids of the roles given to whoever joins with the invite.</ResponseField>

[Discord documentation](https://docs.discord.com/developers/resources/channel#create-channel-invite-jsonform-params)

## FetchMessagesOptions

What `fetchMessages()` takes: how many messages, and from where.

```ts
channel.fetchMessages(options?: FetchMessagesOptions): Promise<Message[]>
```

<ResponseField name="limit" type="number">How many messages, from 1 to 100. Default: 50.</ResponseField>
<ResponseField name="before" type="Snowflake | { id: Snowflake }">Only messages before this one.</ResponseField>
<ResponseField name="after" type="Snowflake | { id: Snowflake }">Only messages after this one.</ResponseField>
<ResponseField name="around" type="Snowflake | { id: Snowflake }">Messages around this one.</ResponseField>

`limit` is checked before anything is sent. A wrong one throws a `RangeError`:

```text
limit is a whole number between 1 and 100, got 500.
```

To start from a date rather than from a message, turn the date into an id with [`snowflakeFromTimestamp()`](/reference/helpers#snowflakefromtimestamp).

[Discord documentation](https://docs.discord.com/developers/resources/message#get-channel-messages-query-string-params)
