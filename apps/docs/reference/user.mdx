---
title: 'User'
description: 'Read a Discord account, get its avatar and send it a private message'
---

A `User` is a Discord account, the same in every server. You get one as the `user` of a [command](/reference/interaction), as `message.author`, as `member.user` and as the `user` of the `memberLeave` [event](/reference/events). For what is specific to one server (nickname, roles, permissions), see [GuildMember](/reference/member).

```ts
import type { User } from 'chapterjs';

async function greet(user: User) {
  if (user.bot) return;
  await user.send({
    content: `Hi ${user.displayName}!`,
    embeds: [{ thumbnail: { url: user.avatarURL({ size: 256 }) } }],
  });
}
```

<Note>
  How your functions receive a user is in [Commands](/commands) and [Events](/events). What a private message can hold is in [Messages](/messages).
</Note>

<Warning>
  Sending a private message fails when the user has closed their private messages or shares no server with the bot. Catch the error when that is fine for you: see [Errors](/reference/errors).
</Warning>

## Properties

<ResponseField name="id" type="Snowflake">
  The unique id Discord gave it.
</ResponseField>

<ResponseField name="createdAt" type="Date">
  When it was created: a Discord id contains its creation date.
</ResponseField>

<ResponseField name="username" type="string">
  The unique name of the account (`@name`).
</ResponseField>

<ResponseField name="globalName" type="string | null">
  The name shown in Discord, when the user chose one.
</ResponseField>

<ResponseField name="displayName" type="string">
  The name to show: the display name, or else the username.
</ResponseField>

<ResponseField name="discriminator" type="string">
  `"0"` for users on the current username system.
</ResponseField>

<ResponseField name="bot" type="boolean">
  Whether the account is a bot.
</ResponseField>

<ResponseField name="system" type="boolean">
  Whether the account is an official Discord system account.
</ResponseField>

<ResponseField name="avatar" type="string | null">
  The hash of the avatar; use `avatarURL()` to get the image.
</ResponseField>

<ResponseField name="banner" type="string | null">
  The hash of the banner; use `bannerURL()` to get the image.
</ResponseField>

<ResponseField name="accentColor" type="number | null">
  The banner color, as a number (`0xff0000`).
</ResponseField>

<ResponseField name="locale" type="Locale | null">
  Only known for the bot itself. See [Locale](/reference/enums#locale).
</ResponseField>

<ResponseField name="flags" type="UserFlagName[]">
  The public badges of the account, by name. See [UserFlagName](#userflagname).
</ResponseField>

## Helpers

These read what the bot remembers: they never send a request.

### avatarURL()

```ts
avatarURL(options?: ImageOptions): string
```

The URL of the avatar; of the default one when none is set. See [ImageOptions](/reference/helpers#imageoptions).

### bannerURL()

```ts
bannerURL(options?: ImageOptions): string | null
```

The URL of the banner, when one is set. See [ImageOptions](/reference/helpers#imageoptions).

### toString()

```ts
toString(): string
```

`<@id>`: mentions the user when put in a message.

### toJSON()

```ts
toJSON(): object
```

The data of Discord as a plain object, with camelCase names.

## Reading from Discord

### fetch()

```ts
fetch(): Promise<User>
```

Asks Discord for the latest data of this user.

## Actions

### createDM()

```ts
createDM(): Promise<DMChannel>
```

Opens the private conversation with this user. See [DMChannel](/reference/channels/dm).

[Discord documentation](https://docs.discord.com/developers/resources/user#create-dm)

### send()

```ts
send(message: MessageInput): Promise<Message>
```

Sends a private message to this user. See [MessageInput](/reference/message-options#messageinput).

## Types

The name of a public badge, as `flags` lists them: one of the keys of [`UserFlags`](/reference/enums#userflags).

| Name | Badge |
| --- | --- |
| `Staff` | Discord Employee |
| `Partner` | Partnered Server Owner |
| `Hypesquad` | HypeSquad Events Member |
| `BugHunterLevel1` | Bug Hunter Level 1 |
| `HypesquadOnlineHouse1` | House Bravery Member |
| `HypesquadOnlineHouse2` | House Brilliance Member |
| `HypesquadOnlineHouse3` | House Balance Member |
| `PremiumEarlySupporter` | Early Nitro Supporter |
| `TeamPseudoUser` | User is a team |
| `BugHunterLevel2` | Bug Hunter Level 2 |
| `VerifiedBot` | Verified Bot |
| `VerifiedDeveloper` | Early Verified Bot Developer |
| `CertifiedModerator` | Moderator Programs Alumni |
| `BotHttpInteractions` | Bot uses only HTTP interactions and is shown in the online member list |

[Discord documentation](https://docs.discord.com/developers/resources/user#user-object-user-flags)

`ImageOptions` is in [Helpers](/reference/helpers#imageoptions).
