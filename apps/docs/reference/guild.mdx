title: 'Guild'
description: 'A Discord server: its members, roles, channels and moderation'

A `Guild` is a server ("guild" is the name Discord gives servers in its API).

```ts
import type { Guild } from 'chapterjs';

async function describe(guild: Guild) {
  const owner = await guild.fetchOwner();
  return `${guild.name} has ${guild.memberCount} members and belongs to ${owner.displayName}.`;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `id` | `Snowflake` | The unique id Discord gave it. |
| `createdAt` | `Date` | When it was created: a Discord id contains its creation date. |
| `name` | `string` | The name of the server. |
| `description` | `string \| null` | The description of the server, when it has one. |
| `ownerId` | `Snowflake` | The id of the user who owns the server. |
| `available` | `boolean` | `false` during an outage of Discord: the data may be out of date. |
| `memberCount` | `number \| null` | How many members the server has. Exact when the bot receives member events, approximate otherwise; `null` when Discord never said it. |
| `features` | `readonly GuildFeature[]` | What the server has enabled or unlocked (`COMMUNITY`, `VANITY_URL`...). |
| `verificationLevel` | `VerificationLevel` | What Discord asks of new members before they can write. |
| `premiumTier` | `PremiumTier` | The boost level of the server. |
| `boostCount` | `number` | How many boosts the server has. |
| `preferredLocale` | `Locale` | The language of the server, used for what Discord sends to it. |
| `vanityUrlCode` | `string \| null` | The code of the custom invite link of the server, when it has one. |
| `systemChannelId` | `Snowflake \| null` | The id of the channel where Discord posts welcome messages. |
| `rulesChannelId` | `Snowflake \| null` | The id of the channel that shows the rules, in a community server. |
| `afkChannelId` | `Snowflake \| null` | The id of the voice channel inactive members are moved to. |
| `joinedAt` | `Date \| null` | When the bot joined the server, when Discord said it. |
| `roles` | `ReadonlyMap<Snowflake, Role>` | The roles of the server, @everyone included. |
| `members` | `ReadonlyMap<Snowflake, GuildMember>` | The members of the server the bot knows: the ones seen the most recently, not all of them (see [Memory](/memory)). |
| `channels` | `ReadonlyMap<Snowflake, GuildChannel \| ThreadChannel>` | The channels and active threads of the server. |
| `emojis` | `ReadonlyMap<Snowflake, GuildEmoji>` | The custom emojis of the server. |
| `everyoneRole` | `Role` | The @everyone role, which every member has. |
| `me` | `GuildMember` | The bot as a member of this server. |


<Info>
  `guild.members` only contains the members the bot has seen. Use `fetchMember()` to get one for sure.
</Info>

## Helpers

These read what the bot already knows: they never send a request.

### iconURL()

```ts
iconURL(options?: ImageOptions): string | null
```

The URL of the icon of the server, when it has one.

### bannerURL()

```ts
bannerURL(options?: ImageOptions): string | null
```

The URL of the banner of the server, when it has one.

### splashURL()

```ts
splashURL(options?: ImageOptions): string | null
```

The URL of the invite background of the server, when it has one.

### toString()

```ts
toString(): string
```

The name of the server.

## Reading from Discord

### fetch()

```ts
fetch(): Promise<Guild>
```

Asks Discord for the latest data of the server.

[Discord documentation](https://docs.discord.com/developers/resources/guild#get-guild)

### fetchMember()

```ts
fetchMember(user: Snowflake | { id: Snowflake }, options?: { force?: boolean }): Promise<GuildMember>
```

A member of the server: from the cache, or else from Discord.

[Discord documentation](https://docs.discord.com/developers/resources/guild#get-guild-member)

### fetchMembers()

```ts
fetchMembers(options?: { limit?: number; after?: Snowflake | { id: Snowflake } }): Promise<GuildMember[]>
```

Members of the server, by pages of 1000 at most, ordered by id. Needs the Server Members intent to be enabled for the bot.

[Discord documentation](https://docs.discord.com/developers/resources/guild#list-guild-members)

### searchMembers()

```ts
searchMembers(query: string, limit?: number): Promise<GuildMember[]>
```

Members whose username or nickname starts with the given text.

[Discord documentation](https://docs.discord.com/developers/resources/guild#search-guild-members)

### fetchOwner()

```ts
fetchOwner(): Promise<GuildMember>
```

The member who owns the server.

## Actions

```ts
edit(options: GuildEditOptions, reason?: string): Promise<Guild>
```

[Discord documentation](https://docs.discord.com/developers/resources/guild#modify-guild)

### leave()

```ts
leave(): Promise<void>
```

Makes the bot leave the server.

[Discord documentation](https://docs.discord.com/developers/resources/user#leave-guild)

### kick()

```ts
kick(user: Snowflake | { id: Snowflake }, reason?: string): Promise<void>
```

Removes a member from the server; they can come back with an invite.

[Discord documentation](https://docs.discord.com/developers/resources/guild#remove-guild-member)

### ban()

```ts
ban(user: Snowflake | { id: Snowflake }, options?: BanOptions): Promise<void>
```

Bans a user from the server, member or not.

[Discord documentation](https://docs.discord.com/developers/resources/guild#create-guild-ban)

### bulkBan()

```ts
bulkBan(users: readonly (Snowflake | { id: Snowflake })[], options?: BanOptions): Promise<{ bannedUsers: Snowflake[]; failedUsers: Snowflake[] }>
```

Bans up to 200 users at once.

Returns the ids of the users that were banned, and of those that could not be.

[Discord documentation](https://docs.discord.com/developers/resources/guild#bulk-guild-ban)

### unban()

```ts
unban(user: Snowflake | { id: Snowflake }, reason?: string): Promise<void>
```

Lifts the ban of a user.

[Discord documentation](https://docs.discord.com/developers/resources/guild#remove-guild-ban)

## Types

### Ban

A ban of a server.

| Field | Type | Description |
| --- | --- | --- |
| `user` | `User` | Who is banned. |
| `reason` | `string \| null` | Why, when a reason was given. |

### BanOptions

| Field | Type | Description |
| --- | --- | --- |
| `reason?` | `string` | Why, shown in the audit log of the server. |
| `deleteMessageSeconds?` | `number` | Also deletes the messages the user sent in the last seconds given: from 0 (the default, nothing) to 604800 (7 days). |

See [Options](/reference/options) for what `edit()`, `createChannel()`, `createRole()` and `createScheduledEvent()` accept, and [Data](/reference/data) for what `fetchAuditLog()`, `fetchScheduledEvents()`, `fetchAutoModerationRules()` and `fetchStickers()` return.
