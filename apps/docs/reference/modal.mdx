`modal()` declares a form, from any file of `src/`; the name of its export is its id. It takes one object, `ModalConfig`, and types `fields` in `run` from it.

```ts src/components/feedback.ts
import { modal } from 'chapterjs';

export default modal({
  title: 'Feedback',
  fields: {
    text: { type: 'text', label: 'What do you think?', style: 'paragraph' },
  },
  async run({ interaction, fields }) {
    await interaction.reply({ content: `Thanks! You wrote: ${fields.text}`, ephemeral: true });
  },
});
```

<Note>
  How to write a form, open it and read what was filled in is in the [guide](/components/modals). This page lists what exists. The place (`where`, `PlaceOf`...) is on the [button() page](/reference/button#the-place).
</Note>

## modal()

```ts
modal<Fields extends ModalFields, Data extends DataShape = {}, Where extends ComponentWhere = 'guild'>(config: ModalConfig<Fields, Data, Where>): ModalDeclaration<Fields, Data>
```

Declares a form. Export the result from any file of `src/`: the name of the export is what tells the form apart, so you never write an id.

### ModalDeclaration

What `modal()` returns: a declaration the framework finds in the exports of a file. Import it where someone uses a command or a component, and open it: `interaction.showModal(report({ userId }))`, or `interaction.showModal(feedback)` for a form without data.

```ts
type ModalDeclaration<Fields extends ModalFields = ModalFields, Data extends DataShape = {}> = { readonly config: unknown } &
  ({} extends Data
    ? ((options?: ModalInstanceOptions<Fields>) => ModalComponent) & ModalComponent
    : {} extends DataInputOf<Data>
      ? ((data?: DataInputOf<Data>, options?: ModalInstanceOptions<Fields>) => ModalComponent) & ModalComponent
      : (data: DataInputOf<Data>, options?: ModalInstanceOptions<Fields>) => ModalComponent)
```

<ResponseField name="config" type="unknown">
  What the file gave to `modal()`, not checked yet.
</ResponseField>

### ModalInstanceOptions

What a form is opened with: its data, and what some fields hold.

<ResponseField name="values" type="ModalPrefill<Fields>">
  What some fields hold when the form opens.
</ResponseField>

### ModalPrefill

What a form can hold when it opens: a value for some of its fields. A `string` for a `text`, a list of values for a `select` or `checkboxes`, one value for a `radio`, a `boolean` for a `checkbox`. The other kinds of fields can't be filled in advance.

## ModalConfig

What a modal file gives to `modal()`.

<ResponseField name="title" type="DynamicText" required>
  The title of the form (45 characters at most): written as is, or a function of `t` and the data, run when the form opens. See [DynamicText](/reference/messages#dynamictext).
</ResponseField>

<ResponseField name="fields" type="ModalFields" required>
  The fields, by name (1 to 5). `run` receives them under the same names.
</ResponseField>

<ResponseField name="run" type="(context: ModalContext<Fields, Data, Where>) => unknown" required>
  What to do when someone sends the form.
</ResponseField>

<ResponseField name="data" type="DataShape">
  What the form carries from the code that opens it to the code that runs when it is sent: a name and a kind for each value. Given when the form is opened, received typed in `run`.
</ResponseField>

<ResponseField name="where" type="ComponentWhere">
  Where the form can be sent from: `'guild'` (servers, the default), `'dm'` (private messages with the bot) or `'both'`. What `run` receives follows it.
</ResponseField>

<ResponseField name="ephemeral" type="boolean">
  Make the answers of the form only visible to who sent it. When a component of a message only the person sees opened it, they already are.
</ResponseField>

[Discord documentation](https://docs.discord.com/developers/interactions/receiving-and-responding#interaction-response-object-modal)

## Fields

### ModalFields

```ts
type ModalFields = Readonly<Record<string, ModalField>>
```

The fields of a form, by name (5 at most). A name is how your code reads the field (`fields.reason`): letters, digits and `_`.

### ModalField

```ts
type ModalField = TextField | SelectField | EntityField | FilesField | RadioField | CheckboxesField | CheckboxField | NoteField
```

One field of a form. Every field but a note has:

<ResponseField name="label" type="DynamicText" required>
  The name of the field, above it (45 characters at most): written as is, or a function of `t` and the data, run when the form opens.
</ResponseField>

<ResponseField name="description" type="DynamicText">
  A help text under the label (100 characters at most): a text, or a function of `t` and the data.
</ResponseField>

[Discord documentation](https://docs.discord.com/developers/components/reference#label)

### TextField

A text the person types.

<ResponseField name="type" type="'text'" required>
  The kind of field: a text.
</ResponseField>

<ResponseField name="style" type="'short' | 'paragraph'">
  One line (`'short'`, the default) or several (`'paragraph'`).
</ResponseField>

<ResponseField name="placeholder" type="DynamicText">
  The text shown while the field is empty (100 characters at most): a text, or a function of `t` and the data.
</ResponseField>

<ResponseField name="required" type="boolean">
  Whether the person must fill it in. `true` by default.
</ResponseField>

<ResponseField name="minLength" type="number">
  The shortest text accepted, in characters (0 to 4000).
</ResponseField>

<ResponseField name="maxLength" type="number">
  The longest text accepted, in characters (1 to 4000).
</ResponseField>

<ResponseField name="value" type="string">
  What the field holds when the form opens (4000 characters at most).
</ResponseField>

[Discord documentation](https://docs.discord.com/developers/components/reference#text-input)

### SelectField

A menu of texts you declare.

<ResponseField name="type" type="'select'" required>
  The kind of field: a menu of texts.
</ResponseField>

<ResponseField name="options" type="SelectOptions" required>
  The options (25 at most), written like the options of a [select menu](/reference/select#selectoptions).
</ResponseField>

<ResponseField name="placeholder" type="DynamicText">
  The text shown when nothing is picked (150 characters at most): a text, or a function of `t` and the data.

<ResponseField name="min" type="number">
  How many options must be picked at least (0 to 25). 1 by default.
</ResponseField>

<ResponseField name="max" type="number">
  How many options can be picked at most (1 to 25). 1 by default.
</ResponseField>

<ResponseField name="required" type="boolean">
  Whether something must be picked. `true` by default.
</ResponseField>

<ResponseField name="placeholder" type="DynamicText">

<ResponseField name="min" type="number">
  How many things must be picked at least (0 to 25). 1 by default.

<ResponseField name="channelTypes" type="readonly ChannelType[]">

## What run receives

### ModalContext

What `run` receives when the form is sent: the place as [PlaceOf](/reference/button#placeof) gives it with a [ModalInteraction](/reference/interaction#modalinteraction), and:

<ResponseField name="user" type="User" required>
  Who sent the form.
</ResponseField>

<ResponseField name="fields" type="FieldValuesOf<Fields>" required>
  What the person filled in.
</ResponseField>

<ResponseField name="data" type="DataValuesOf<Data>" required>
  What the form carries, as declared in `data`.
</ResponseField>

<ResponseField name="message" type="Message | null" required>
  The message whose button or menu opened the form; `null` when a command did.
</ResponseField>

### FieldValuesOf

```ts
type FieldValuesOf<Fields extends ModalFields> = { [Name in keyof Fields]: FieldValue<Fields[Name]> }
```

What the person filled in, typed field by field. Notes are not there.

### FieldValue

What `run` receives for a field, from its declaration:

| Field | `FieldValue` |
| --- | --- |
| `TextField` | `string`, or `string \| undefined` with `required: false` |
| `SelectField` | `OptionValue<Options>[]` |
| `EntityField` | `User[]`, `Role[]`, `(User \| Role)[]` or `Channel[]` |
| `FilesField` | [`Attachment`](/reference/data#attachment)`[]` |
| `RadioField` | `OptionValue<Options>`, or `\| undefined` with `required: false` |
| `CheckboxesField` | `OptionValue<Options>[]` |
| `CheckboxField` | `boolean` |

[Discord documentation](https://docs.discord.com/developers/interactions/receiving-and-responding#interaction-object-modal-submit-data-structure)
