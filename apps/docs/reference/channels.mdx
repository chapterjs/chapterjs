There are several kinds of channels, and each kind has its own class. They all share what `Channel` has.

## Which kind is it?

A channel you get from `guild.channels` or `message.channel` can be of any kind. Ask it before using what only one kind has: inside the `if`, your editor knows the kind.

| Method | True for | Class |
| --- | --- | --- |
| `isText()` | A text or announcement channel of a server | `TextChannel` |
| `isVoice()` | A voice or stage channel | `VoiceChannel` |
| `isCategory()` | A category | `CategoryChannel` |
| `isForum()` | A forum or media channel | `ForumChannel` |
| `isThread()` | A thread, or a post of a forum | `ThreadChannel` |
| `isDM()` | A private conversation | `DMChannel` |
| `isGuildChannel()` | Any channel of a server that is not a thread | `GuildChannel` |
| `isTextBased()` | Any channel messages can be sent in | `TextBasedChannel` |

```ts
import type { Channel } from 'chapterjs';

async function announce(channel: Channel, text: string) {
  if (!channel.isTextBased()) return; // a category or a forum: no messages there
  await channel.send(text);

  if (channel.isThread() && channel.archived) await channel.unarchive();
}
```

## Channel

What every channel has.

### Channel properties

| Property | Type | Description |
| --- | --- | --- |
| `id` | `Snowflake` | The unique id Discord gave it. |
| `createdAt` | `Date` | When it was created: a Discord id contains its creation date. |
| `type` | `ChannelType` | The kind of channel, as a value of `ChannelType`. |
| `guildId` | `Snowflake \| null` | The id of the server of the channel; `null` for a private one. |
| `guild` | `Guild \| null` | The server of the channel, when there is one and it is known. |

### Channel methods

#### fetch()

```ts
fetch(): Promise<Channel>
```

Asks Discord for the latest data of the channel.

#### delete()

```ts
delete(reason?: string): Promise<void>
```

Deletes the channel (closes it, for a private conversation).

[Discord documentation](https://docs.discord.com/developers/resources/channel#deleteclose-channel)

#### toString()

```ts
toString(): string
```

`<#id>`: links the channel when put in a message.


## Channels with messages

`TextChannel`, `VoiceChannel`, `ThreadChannel` and `DMChannel` can all send and read messages. They share these properties and methods.

```ts
import type { TextChannel } from 'chapterjs';

async function clean(channel: TextChannel) {
  const messages = await channel.fetchMessages({ limit: 100 });
  const fromBots = messages.filter(message => message.author.bot);
  const deleted = await channel.bulkDelete(fromBots, 'Cleaning bot messages');
  await channel.send(`Deleted ${deleted} messages.`);
}
```

### Shared properties

| Property | Type | Description |
| --- | --- | --- |
| `messages` | `ReadonlyMap<Snowflake, Message>` | The messages of the channel the bot remembers. |
| `lastMessageId` | `Snowflake \| null` | The id of the last message sent in the channel, when known. |

### Shared methods

#### send()

```ts
send(message: MessageInput): Promise<Message>
```

Sends a message in the channel.

[Discord documentation](https://docs.discord.com/developers/resources/message#create-message)

#### fetchMessage()

```ts
fetchMessage(id: Snowflake, options?: { force?: boolean }): Promise<Message>
```

A message of the channel: from the cache, or else from Discord.

[Discord documentation](https://docs.discord.com/developers/resources/message#get-channel-message)

#### fetchMessages()

```ts
fetchMessages(options?: FetchMessagesOptions): Promise<Message[]>
```

The latest messages of the channel, newest first.

[Discord documentation](https://docs.discord.com/developers/resources/message#get-channel-messages)

#### bulkDelete()

```ts
bulkDelete(messages: readonly (Snowflake | { id: Snowflake })[], reason?: string): Promise<number>
```

Deletes several messages at once. Messages older than two weeks can't be deleted in bulk: they are left out, and their number is not counted in the result.

Returns how many messages were deleted.

[Discord documentation](https://docs.discord.com/developers/resources/message#bulk-delete-messages)

#### sendTyping()

```ts
sendTyping(): Promise<void>
```

Shows "the bot is typing…" for 10 seconds, or until it sends a message.

[Discord documentation](https://docs.discord.com/developers/resources/channel#trigger-typing-indicator)

#### fetchPins()

```ts
fetchPins(): Promise<Message[]>
```

The pinned messages of the channel, latest pin first.

[Discord documentation](https://docs.discord.com/developers/resources/message#get-channel-pins)

### FetchMessagesOptions

A `?` after a name means the field can be left out.

| Field | Type | Description |
| --- | --- | --- |
| `limit?` | `number` | How many messages, from 1 to 100. Default: 50. |
| `before?` | `Snowflake \| { id: Snowflake }` | Only messages before this one. |
| `after?` | `Snowflake \| { id: Snowflake }` | Only messages after this one. |
| `around?` | `Snowflake \| { id: Snowflake }` | Messages around this one. |

<Info>
  `channel.messages` is empty by default: the bot does not keep messages in memory, since most bots never read an old one. `fetchMessage()` and `fetchMessages()` always work.
</Info>

## GuildChannel

A channel of a server that is not a thread. `TextChannel`, `VoiceChannel`, `CategoryChannel` and `ForumChannel` have everything listed here, plus what `Channel` has.

### GuildChannel properties

| Property | Type | Description |
| --- | --- | --- |
| `guildId` | `Snowflake` | The id of the server of the channel. |
| `name` | `string` | The name of the channel. |
| `position` | `number` | Where the channel is in the list. |
| `parentId` | `Snowflake \| null` | The id of the category of the channel, when it is in one. |
| `parent` | `CategoryChannel \| null` | The category of the channel, when it is in one and it is known. |
| `nsfw` | `boolean` | Whether the channel is age-restricted. |
| `permissionOverwrites` | `PermissionOverwrite[]` | What roles and members are allowed or denied in this channel. |

### GuildChannel methods

#### permissionsFor()

```ts
permissionsFor(member: GuildMember): Permissions
```

What a member can do in this channel: their permissions in the server, changed by the overwrites of the channel.

[Discord documentation](https://docs.discord.com/developers/topics/permissions#permission-overwrites)

#### edit()

```ts
edit(options: GuildChannelEditOptions, reason?: string): Promise<this>
```

Changes the channel.

[Discord documentation](https://docs.discord.com/developers/resources/channel#modify-channel)

#### setPermissions()

```ts
setPermissions(target: Role | GuildMember | User, permissions: { allow?: PermissionResolvable; deny?: PermissionResolvable }, reason?: string): Promise<void>
```

Allows or denies permissions to a role or a member in this channel. Permissions that are in neither list follow the server.

[Discord documentation](https://docs.discord.com/developers/resources/channel#edit-channel-permissions)

#### deletePermissions()

```ts
deletePermissions(target: Snowflake | { id: Snowflake }, reason?: string): Promise<void>
```

Removes what was set for a role or a member in this channel.

[Discord documentation](https://docs.discord.com/developers/resources/channel#delete-channel-permission)

#### createInvite()

```ts
createInvite(options?: InviteCreateOptions, reason?: string): Promise<Invite>
```

Creates an invite to this channel.

[Discord documentation](https://docs.discord.com/developers/resources/channel#create-channel-invite)

#### fetchInvites()

```ts
fetchInvites(): Promise<Invite[]>
```

The invites that lead to this channel.

[Discord documentation](https://docs.discord.com/developers/resources/channel#get-channel-invites)

#### createWebhook()

```ts
createWebhook(options: Camelize<CreateWebhookJSONParams>, reason?: string): Promise<Webhook>
```

Creates a webhook that posts in this channel.

[Discord documentation](https://docs.discord.com/developers/resources/webhook#create-webhook)

#### fetchWebhooks()

```ts
fetchWebhooks(): Promise<Webhook[]>
```

The webhooks that post in this channel.

[Discord documentation](https://docs.discord.com/developers/resources/webhook#get-channel-webhooks)

### PermissionOverwrite

What a role or a member is allowed or denied in one channel.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `Snowflake` | The id of the role or of the member. |
| `type` | `'role' \| 'member'` |  |
| `allow` | `Permissions` | What is allowed, whatever the server says. |
| `deny` | `Permissions` | What is denied, whatever the server says. |


```ts
import type { TextChannel } from 'chapterjs';

async function lock(channel: TextChannel) {
  const everyone = channel.guild?.everyoneRole;
  if (!everyone) return;
  // Nobody can write any more, but everyone still reads.
  await channel.setPermissions(everyone, { deny: ['SendMessages'] }, 'Channel locked');
}
```

## TextChannel

A text or announcement channel of a server. Has everything of `GuildChannel` and of [channels with messages](#channels-with-messages).

### TextChannel properties

| Property | Type | Description |
| --- | --- | --- |
| `topic` | `string \| null` | The topic shown at the top of the channel. |
| `slowmode` | `number` | How many seconds a member waits between two messages (slowmode). |
| `isAnnouncement` | `boolean` | Whether it is an announcement channel, which servers can follow. |

### TextChannel methods

#### startThread()

```ts
startThread(options: ThreadCreateOptions, reason?: string): Promise<ThreadChannel>
```

Starts a thread that is not attached to a message. To start one from a message, use `message.startThread()`.

[Discord documentation](https://docs.discord.com/developers/resources/channel#start-thread-without-message)

#### follow()

```ts
follow(target: Snowflake | { id: Snowflake }, reason?: string): Promise<void>
```

Makes another channel receive what is published in this announcement channel.

[Discord documentation](https://docs.discord.com/developers/resources/channel#follow-announcement-channel)

## VoiceChannel

A voice or stage channel: people talk in it, and can write too. Has everything of `GuildChannel` and of [channels with messages](#channels-with-messages).

### VoiceChannel properties

| Property | Type | Description |
| --- | --- | --- |
| `bitrate` | `number` | The audio quality, in bits per second. |
| `userLimit` | `number` | How many people can join; `0` means no limit. |
| `rtcRegion` | `string \| null` | The voice region of the channel; `null` when Discord picks it. |
| `isStage` | `boolean` | Whether it is a stage channel, where a few speak and the others listen. |

### VoiceChannel methods

#### setStatus()

```ts
setStatus(status: string | null, reason?: string): Promise<void>
```

Sets the status shown under the name of the voice channel; `null` removes it.

[Discord documentation](https://docs.discord.com/developers/resources/channel#set-voice-channel-status)

## ForumChannel

A forum or media channel: it only contains posts, which are threads. Has everything of `GuildChannel`.

### ForumChannel properties

| Property | Type | Description |
| --- | --- | --- |
| `topic` | `string \| null` | The guidelines of the forum. |
| `availableTags` | `ForumTag[]` | The tags posts of this forum can have. |

### ForumChannel methods

#### createPost()

```ts
createPost(options: ForumPostOptions, reason?: string): Promise<ThreadChannel>
```

Creates a post in the forum.

[Discord documentation](https://docs.discord.com/developers/resources/channel#start-thread-in-forum-or-media-channel)

A `?` after a name means the field can be left out.

### ForumPostOptions

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | The title of the post. |
| `message` | `MessageInput` | The first message of the post. |
| `appliedTags?` | `Snowflake[]` | The ids of the tags of the post. |
| `autoArchiveDuration?` | `60 \| 1440 \| 4320 \| 10080` | After how many minutes without activity the post is archived. |
| `slowmode?` | `number` | Slowmode of the post, in seconds. |


```ts
import type { ForumChannel } from 'chapterjs';

async function report(forum: ForumChannel, title: string, details: string) {
  const post = await forum.createPost({
    name: title,
    message: { content: details },
    autoArchiveDuration: 1440,
  });
  return `Created ${post}`;
}
```

## ThreadChannel

A thread, or a post of a forum. Has everything of `Channel` and of [channels with messages](#channels-with-messages).

### ThreadChannel properties

| Property | Type | Description |
| --- | --- | --- |
| `guildId` | `Snowflake` | The id of the server of the thread. |
| `name` | `string` | The name of the thread. |
| `parentId` | `Snowflake \| null` | The id of the channel the thread was created in. |
| `parent` | `TextChannel \| ForumChannel \| null` | The channel the thread was created in, when it is known. |
| `ownerId` | `Snowflake \| null` | The id of the user who created the thread. |
| `archived` | `boolean` | Whether the thread is archived. |
| `locked` | `boolean` | Whether only moderators can unarchive it. |
| `isPrivate` | `boolean` | Whether only invited members and moderators can see it. |
| `archivedAt` | `Date \| null` | When the thread was archived or unarchived for the last time. |
| `memberCount` | `number` | An approximate count of the members of the thread (stops at 50). |
| `appliedTags` | `readonly Snowflake[]` | The ids of the tags of the post, in a forum. |

### ThreadChannel methods

#### permissionsFor()

```ts
permissionsFor(member: GuildMember): Permissions
```

Threads inherit the permissions of the channel they are in.

#### edit()

```ts
edit(options: ThreadEditOptions, reason?: string): Promise<this>
```

Changes the thread: name, archive, lock, slowmode, tags.

[Discord documentation](https://docs.discord.com/developers/resources/channel#modify-channel)

#### archive()

```ts
archive(reason?: string): Promise<this>
```

Archives the thread: it leaves the channel list but can come back.

#### unarchive()

```ts
unarchive(reason?: string): Promise<this>
```

Brings an archived thread back.

#### join()

```ts
join(): Promise<void>
```

Makes the bot join the thread.

#### leave()

```ts
leave(): Promise<void>
```

Makes the bot leave the thread.

#### addMember()

```ts
addMember(user: Snowflake | { id: Snowflake }): Promise<void>
```

Adds a member to the thread.

[Discord documentation](https://docs.discord.com/developers/resources/channel#add-thread-member)

#### removeMember()

```ts
removeMember(user: Snowflake | { id: Snowflake }): Promise<void>
```

Removes a member from the thread.

[Discord documentation](https://docs.discord.com/developers/resources/channel#remove-thread-member)

#### fetchMembers()

```ts
fetchMembers(options?: { limit?: number; after?: Snowflake }): Promise<ThreadMember[]>
```

Who is in the thread (100 at most per call).

[Discord documentation](https://docs.discord.com/developers/resources/channel#list-thread-members)

## DMChannel

A private conversation between the bot and a user. Has everything of `Channel` and of [channels with messages](#channels-with-messages). To write to someone, `user.send()` is shorter.

### DMChannel properties

| Property | Type | Description |
| --- | --- | --- |
| `recipientId` | `Snowflake \| null` | The id of the user the bot talks to. |
| `recipient` | `User \| null` | The user the bot talks to, when it is known. |

See [Options](/reference/options) for what `edit()`, `createInvite()`, `createWebhook()` and `startThread()` accept.
