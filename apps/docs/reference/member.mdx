---
title: 'GuildMember'
description: 'A user as a member of one server: nickname, roles, permissions and moderation'
---

A `GuildMember` is a [user](/reference/user) in one server. The same person has one `User`, and one `GuildMember` per server they are in.

```ts
import type { GuildMember } from 'chapterjs';

async function mute(member: GuildMember, moderator: GuildMember) {
  if (!moderator.permissions.has('ModerateMembers')) return 'You are not allowed to do that.';
  if (!moderator.isHigherThan(member)) return 'You can only time out members below you.';

  await member.timeout(10 * 60 * 1000, `Timed out by ${moderator.displayName}`);
  return `${member.displayName} is timed out for 10 minutes.`;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `guildId` | `Snowflake` | The id of the server. |
| `user` | `User` | The account of the member. |
| `id` | `Snowflake` | The id of the user. |
| `guild` | `Guild \| null` | The server, when it is known. |
| `nick` | `string \| null` | The nickname of the member in this server, when they have one. |
| `displayName` | `string` | The name to show: nickname, or display name, or username. |
| `roleIds` | `readonly Snowflake[]` | The ids of the roles of the member (@everyone is not listed). |
| `roles` | `Role[]` | The roles of the member, @everyone included, highest first. |
| `highestRole` | `Role \| null` | The highest role of the member in the hierarchy. |
| `joinedAt` | `Date \| null` | When the member joined the server. |
| `boostingSince` | `Date \| null` | Since when the member boosts the server. |
| `pending` | `boolean` | Whether the member has not passed the membership screening yet. |
| `timeoutUntil` | `Date \| null` | Until when the member is timed out; `null` when they are not. |
| `isTimedOut` | `boolean` | Whether the member is timed out right now. |
| `isOwner` | `boolean` | Whether the member owns the server. |
| `permissions` | `Permissions` | What the member can do in the server (channels may change it: see `permissionsIn`). |

## Helpers

These read what the bot already knows: they never send a request.

### permissionsIn()

```ts
permissionsIn(channel: GuildChannel): Permissions
```

What the member can do in a channel of the server.

### avatarURL()

```ts
avatarURL(options?: ImageOptions): string
```

The avatar of the member in this server, or else of their account.

### isHigherThan()

```ts
isHigherThan(other: GuildMember): boolean
```

Whether this member is above another one in the role hierarchy, which is what allows to kick, ban or rename them.

[Discord documentation](https://docs.discord.com/developers/topics/permissions#permission-hierarchy)

### hasRole()

```ts
hasRole(role: Snowflake | Role): boolean
```

Whether the member has a role.

### toString()

```ts
toString(): string
```

`<@id>`: mentions the member when put in a message.

## Actions

### edit()

```ts
edit(options: MemberEditOptions, reason?: string): Promise<GuildMember>
```

Changes the member.

[Discord documentation](https://docs.discord.com/developers/resources/guild#modify-guild-member)

### setNick()

```ts
setNick(nick: string | null, reason?: string): Promise<GuildMember>
```

Changes the nickname of the member; `null` removes it.

### addRole()

```ts
addRole(role: Snowflake | Role, reason?: string): Promise<void>
```

Gives a role to the member.

[Discord documentation](https://docs.discord.com/developers/resources/guild#add-guild-member-role)

### removeRole()

```ts
removeRole(role: Snowflake | Role, reason?: string): Promise<void>
```

Takes a role from the member.

[Discord documentation](https://docs.discord.com/developers/resources/guild#remove-guild-member-role)

### timeout()

```ts
timeout(duration: number, reason?: string): Promise<GuildMember>
```

Prevents the member from writing, reacting and speaking for a while.

- `duration`: how long, in milliseconds (28 days at most)

### removeTimeout()

```ts
removeTimeout(reason?: string): Promise<GuildMember>
```

Ends the timeout of the member.

### kick()

```ts
kick(reason?: string): Promise<void>
```

Removes the member from the server; they can come back with an invite.

[Discord documentation](https://docs.discord.com/developers/resources/guild#remove-guild-member)

### ban()

```ts
ban(options?: BanOptions): Promise<void>
```

Bans the member from the server.

[Discord documentation](https://docs.discord.com/developers/resources/guild#create-guild-ban)

### send()

```ts
send(message: MessageInput): Promise<Message>
```

Sends a private message to the member.

## Types

A `?` after a name means the field can be left out.

### MemberEditOptions

| Field | Type | Description |
| --- | --- | --- |
| `nick?` | `string \| null` | The nickname; `null` removes it. |
| `roles?` | `(Snowflake \| Role)[]` | Replaces every role of the member. |
| `mute?` | `boolean` | Mutes the member in voice channels. |
| `deaf?` | `boolean` | Deafens the member in voice channels. |
| `voiceChannel?` | `Snowflake \| { id: Snowflake } \| null` | Moves the member to another voice channel; `null` disconnects them. |
| `timeoutUntil?` | `Date \| null` | Until when the member is timed out; `null` ends the timeout. |

### BanOptions

| Field | Type | Description |
| --- | --- | --- |
| `reason?` | `string` | Why, shown in the audit log of the server. |
| `deleteMessageSeconds?` | `number` | Also deletes the messages the user sent in the last seconds given: from 0 (the default, nothing) to 604800 (7 days). |
