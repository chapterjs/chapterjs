---
title: 'GuildMember'
description: 'Read the nickname, roles and permissions of a member and moderate them: timeout, kick, ban'
---

A `GuildMember` is a [user](/reference/user) as a member of one server: the same person has one `User`, and one `GuildMember` per server they are in. You get one as the `member` of a [command](/reference/interaction) used in a server, with the events about members and messages, and from `guild.members` or `guild.fetchMember()`.

```ts
import type { GuildMember } from 'chapterjs';

async function mute(member: GuildMember, moderator: GuildMember) {
  if (!moderator.permissions.has('ModerateMembers')) return 'You are not allowed to do that.';
  if (!moderator.isHigherThan(member)) return 'You can only time out members below you.';
  await member.timeout(10 * 60 * 1000, `Timed out by ${moderator.displayName}`);
  return `${member.displayName} is timed out for 10 minutes.`;
}
```

<Note>
  How your functions receive a member is in [Commands](/commands) and [Events](/events). Which members the bot remembers is in [Memory](/memory).
</Note>

## Properties

<ResponseField name="guildId" type="Snowflake">
  The id of the server.
</ResponseField>

<ResponseField name="user" type="User">
  The account of the member.
</ResponseField>

<ResponseField name="id" type="Snowflake">
  The id of the user.
</ResponseField>

<ResponseField name="guild" type="Guild">
  The server the member is in.
</ResponseField>

<ResponseField name="nick" type="string | null">
  The nickname of the member in this server, when they have one.
</ResponseField>

<ResponseField name="displayName" type="string">
  The name to show: nickname, or display name, or username.
</ResponseField>

<ResponseField name="roleIds" type="readonly Snowflake[]">
  The ids of the roles of the member (@everyone is not listed).
</ResponseField>

<ResponseField name="roles" type="Role[]">
  The roles of the member, @everyone included, highest first.
</ResponseField>

<ResponseField name="highestRole" type="Role">
  The highest role of the member in the hierarchy; @everyone at least.
</ResponseField>

<ResponseField name="joinedAt" type="Date | null">
  When the member joined the server.
</ResponseField>

<ResponseField name="boostingSince" type="Date | null">
  Since when the member boosts the server.
</ResponseField>

<ResponseField name="pending" type="boolean">
  Whether the member has not passed the membership screening yet.
</ResponseField>

<ResponseField name="timeoutUntil" type="Date | null">
  Until when the member is timed out; `null` when they are not.
</ResponseField>

<ResponseField name="isTimedOut" type="boolean">
  Whether the member is timed out right now.
</ResponseField>

<ResponseField name="isOwner" type="boolean">
  Whether the member owns the server.
</ResponseField>

<ResponseField name="permissions" type="Permissions">
  What the member can do in the server (channels may change it: see `permissionsIn`). See [Permissions](/reference/permissions).
</ResponseField>

## Helpers

These read what the bot remembers: they never send a request.

### permissionsIn()

```ts
permissionsIn(channel: GuildChannel): Permissions
```

What the member can do in a channel of the server.

### avatarURL()

```ts
avatarURL(options?: ImageOptions): string
```

The avatar of the member in this server, or else of their account. See [ImageOptions](/reference/helpers#imageoptions).

### isHigherThan()

```ts
isHigherThan(other: GuildMember): boolean
```

Whether this member is above another one in the role hierarchy, which is what allows to kick, ban or rename them.

[Discord documentation](https://docs.discord.com/developers/topics/permissions#permission-hierarchy)

### hasRole()

```ts
hasRole(role: Snowflake | Role): boolean
```

Whether the member has a role.

### toString()

```ts
toString(): string
```

`<@id>`: mentions the member when put in a message.

### toJSON()

```ts
toJSON(): object
```

The data of Discord as a plain object, with camelCase names.

## Actions

### edit()

```ts
edit(options: MemberEditOptions, reason?: string): Promise<GuildMember>
```

Changes the member. See [MemberEditOptions](#membereditoptions).

[Discord documentation](https://docs.discord.com/developers/resources/guild#modify-guild-member)

### setNick()

```ts
setNick(nick: string | null, reason?: string): Promise<GuildMember>
```

Changes the nickname of the member; `null` removes it.

### addRole()

```ts
addRole(role: Snowflake | Role, reason?: string): Promise<void>
```

Gives a role to the member.

[Discord documentation](https://docs.discord.com/developers/resources/guild#add-guild-member-role)

### removeRole()

```ts
removeRole(role: Snowflake | Role, reason?: string): Promise<void>
```

Takes a role from the member.

[Discord documentation](https://docs.discord.com/developers/resources/guild#remove-guild-member-role)

### timeout()

```ts
timeout(duration: number, reason?: string): Promise<GuildMember>
```

Prevents the member from writing, reacting and speaking for a while. `duration` is how long, in milliseconds (28 days at most).

### removeTimeout()

```ts
removeTimeout(reason?: string): Promise<GuildMember>
```

Ends the timeout of the member.

### kick()

```ts
kick(reason?: string): Promise<void>
```

Removes the member from the server; they can come back with an invite.

[Discord documentation](https://docs.discord.com/developers/resources/guild#remove-guild-member)

### ban()

```ts
ban(options?: BanOptions): Promise<void>
```

Bans the member from the server. See [BanOptions](#banoptions).

[Discord documentation](https://docs.discord.com/developers/resources/guild#create-guild-ban)

### send()

```ts
send(message: MessageInput): Promise<Message>
```

Sends a private message to the member. See [MessageInput](/reference/message-options#messageinput).

## Types

### BanOptions

What `ban()` takes, on a member or on a [server](/reference/guild#ban). Every field can be left out.

<ResponseField name="reason" type="string">
  Why, shown in the audit log of the server.
</ResponseField>

<ResponseField name="deleteMessageSeconds" type="number">
  Also deletes the messages the user sent in the last seconds given: from 0 (the default, nothing) to 604800 (7 days).
</ResponseField>

### MemberEditOptions

What `edit()` takes. Every field can be left out: only what you pass changes.

<ResponseField name="nick" type="string | null">
  The nickname; `null` removes it.
</ResponseField>

<ResponseField name="roles" type="(Snowflake | Role)[]">
  Replaces every role of the member.
</ResponseField>

<ResponseField name="mute" type="boolean">
  Mutes the member in voice channels.
</ResponseField>

<ResponseField name="deaf" type="boolean">
  Deafens the member in voice channels.
</ResponseField>

<ResponseField name="voiceChannel" type="Snowflake | { id: Snowflake } | null">
  Moves the member to another voice channel; `null` disconnects them.
</ResponseField>

<ResponseField name="timeoutUntil" type="Date | null">
  Until when the member is timed out; `null` ends the timeout.
</ResponseField>
