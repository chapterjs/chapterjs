## GuildEmoji

A custom emoji of a server. Putting one in a text shows it:

```ts
import type { Guild } from 'chapterjs';

async function example(guild: Guild) {
  const emoji = [...guild.emojis.values()].find(emoji => emoji.name === 'party');
  if (!emoji) return;
  const channel = guild.channels.get(guild.systemChannelId ?? '');
  if (channel?.isTextBased()) await channel.send(`Welcome! ${emoji}`);
}
```

### GuildEmoji properties

| Property | Type | Description |
| --- | --- | --- |
| `id` | `Snowflake` | The unique id Discord gave it. |
| `createdAt` | `Date` | When it was created: a Discord id contains its creation date. |
| `guildId` | `Snowflake` | The id of the server of the emoji. |
| `name` | `string` | The name of the emoji, without the colons. |
| `animated` | `boolean` | Whether the emoji moves. |
| `available` | `boolean` | `false` when the server lost the boosts that gave it this emoji. |
| `managed` | `boolean` | Whether the emoji belongs to an integration. |
| `roleIds` | `readonly Snowflake[]` | The ids of the roles allowed to use the emoji; empty for everyone. |

### GuildEmoji methods

#### url()

```ts
url(options?: ImageOptions): string
```

The URL of the image of the emoji.

#### edit()

```ts
edit(options: { name?: string; roles?: (Snowflake | { id: Snowflake })[] | null }, reason?: string): Promise<GuildEmoji>
```

Renames the emoji, or changes which roles can use it.

[Discord documentation](https://docs.discord.com/developers/resources/emoji#modify-guild-emoji)

#### delete()

```ts
delete(reason?: string): Promise<void>
```

Deletes the emoji.

[Discord documentation](https://docs.discord.com/developers/resources/emoji#delete-guild-emoji)

#### toString()

```ts
toString(): string
```

`<:name:id>`: shows the emoji when put in a message.


## Invite

```ts
import type { TextChannel } from 'chapterjs';

async function invite(channel: TextChannel) {
  const invite = await channel.createInvite({ maxAge: 3600, maxUses: 1, unique: true });
  return invite.url; // https://discord.gg/...
}
```

### Invite properties

| Property | Type | Description |
| --- | --- | --- |
| `inviter` | `User \| null` | Who created the invite, when Discord says it. |
| `inviter` | `User \| null` | Who created the invite, when Discord says it. |
| `code` | `string` | The unique code of the invite (`discord.gg/code`). |
| `url` | `string` | The link to share. |
| `guildId` | `Snowflake \| null` | The id of the server the invite leads to. |
| `channelId` | `Snowflake \| null` | The id of the channel the invite leads to. |
| `expiresAt` | `Date \| null` | When the invite stops working; `null` when it never does. |
| `uses` | `number \| null` | How many times the invite was used, when Discord says it. |
| `maxUses` | `number \| null` | How many times the invite can be used; `0` means no limit. |
| `temporary` | `boolean` | Whether members who joined with it are kicked when they go offline. |

### Invite methods

#### delete()

```ts
delete(reason?: string): Promise<void>
```

Deletes the invite: its link stops working.

[Discord documentation](https://docs.discord.com/developers/resources/invite#delete-invite)

#### toString()

```ts
toString(): string
```

The link to share.


## Webhook

A webhook posts messages in a channel under any name and avatar.

```ts
import type { TextChannel } from 'chapterjs';

async function relay(channel: TextChannel, author: string, text: string) {
  const webhook = await channel.createWebhook({ name: 'Relay' });
  await webhook.send({ content: text, username: author });
}
```

<Info>
  A bot can only post with the webhooks it created: check `webhook.canSend`. The token of a webhook is a secret and is never shown when you log a webhook.
</Info>

### Webhook properties

| Property | Type | Description |
| --- | --- | --- |
| `id` | `Snowflake` | The unique id Discord gave it. |
| `createdAt` | `Date` | When it was created: a Discord id contains its creation date. |
| `name` | `string \| null` | The default name the webhook posts with. |
| `channelId` | `Snowflake \| null` | The id of the channel the webhook posts in. |
| `guildId` | `Snowflake \| null` | The id of the server of the webhook. |
| `canSend` | `boolean` | Whether the bot can post with it: only webhooks it created. |

### Webhook methods

#### send()

```ts
send(message: string | WebhookMessageOptions): Promise<Message>
```

Posts a message with the webhook.

[Discord documentation](https://docs.discord.com/developers/resources/webhook#execute-webhook)

#### edit()

```ts
edit(options: Camelize<ModifyWebhookJSONParams>, reason?: string): Promise<Webhook>
```

Changes the name, the avatar or the channel of the webhook.

[Discord documentation](https://docs.discord.com/developers/resources/webhook#modify-webhook)

#### delete()

```ts
delete(reason?: string): Promise<void>
```

Deletes the webhook.

[Discord documentation](https://docs.discord.com/developers/resources/webhook#delete-webhook)
