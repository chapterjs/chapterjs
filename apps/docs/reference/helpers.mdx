Small functions exported by `chapterjs` to write messages and work with ids.

## Mentions

A structure put in a text becomes its mention: `` `${user}` `` is `<@id>`, `` `${channel}` `` is `<#id>`, `` `${role}` `` is `<@&id>`. When you only have an id, use these:

| Function | Result | Shown by Discord as |
| --- | --- | --- |
| `userMention(id)` | `<@id>` | A mention of the user |
| `channelMention(id)` | `<#id>` | A link to the channel |
| `roleMention(id)` | `<@&id>` | A mention of the role |
| `commandMention(name, id)` | `</name:id>` | A clickable slash command |
| `emojiMention(name, id, animated?)` | `<:name:id>` | The custom emoji |

`GuildNavigation.Customize`, `.Browse`, `.Guide` and `.LinkedRoles` link to the matching tab of the current server.

## Dates

`timestamp()` writes a date that each reader sees in their own timezone and language.

```ts
import { timestamp, TimestampStyle } from 'chapterjs';

const ends = new Date(Date.now() + 3600_000);
const text = `The giveaway ends ${timestamp(ends, TimestampStyle.Relative)}`; // "ends in 1 hour"
```

| Style | Example |
| --- | --- |
| `TimestampStyle.ShortTime` | 16:20 |
| `TimestampStyle.MediumTime` | 16:20:30 |
| `TimestampStyle.ShortDate` | 20/04/2021 |
| `TimestampStyle.LongDate` | April 20, 2021 |
| `TimestampStyle.LongDateShortTime` (default) | April 20, 2021 at 16:20 |
| `TimestampStyle.FullDateShortTime` | Tuesday, April 20, 2021 at 16:20 |
| `TimestampStyle.ShortDateShortTime` | 20/04/2021, 16:20 |
| `TimestampStyle.ShortDateMediumTime` | 20/04/2021, 16:20:30 |
| `TimestampStyle.Relative` | 4 years ago |

## Ids

| Function | Description |
| --- | --- |
| `isSnowflake(value)` | Whether a value looks like a Discord id. Useful to check what a user typed. |
| `snowflakeTimestamp(id)` | When the thing was created, in milliseconds. Structures already have `createdAt`. |
| `snowflakeFromTimestamp(date)` | The smallest id created at a date: lets `before` and `after` options start from a date. |

```ts
import { snowflakeFromTimestamp, type TextChannel } from 'chapterjs';

async function sinceYesterday(channel: TextChannel) {
  const yesterday = Date.now() - 24 * 3600 * 1000;
  return channel.fetchMessages({ after: snowflakeFromTimestamp(yesterday), limit: 100 });
}
```

## Images

Methods that end with `URL` (`user.avatarURL()`, `guild.iconURL()`, `role.iconURL()`...) take the same options:

| Field | Type | Description |
| --- | --- | --- |
| `format?` | `ImageFormat` | The file format. By default: WebP, which Discord recommends since it works for still and animated images, whatever was uploaded. |
| `size?` | `ImageSize` | The size in pixels: a power of two between 16 and 4096. |
| `animated?` | `boolean` | `false` to get the first frame of an animated image. By default an animated image stays animated. |


Sizes are powers of two from 16 to 4096: `16`, `32`, `64`, `128`, `256`, `512`, `1024`, `2048`, `4096`. Formats are `'webp'` (default), `'png'`, `'jpg'` and `'gif'`.
