---
title: 'Invite'
description: 'Read the link, the uses and the expiry of an invite, and delete it'
---

An `Invite` is an invite to a server. You get one from `channel.createInvite()`, `channel.fetchInvites()` or `guild.fetchInvites()`.

```ts
import type { TextChannel } from 'chapterjs';

async function invite(channel: TextChannel) {
  const invite = await channel.createInvite({ maxAge: 3600, maxUses: 1, unique: true });
  return invite.url; // https://discord.gg/...
}
```

<Note>
  What `createInvite()` takes is in [InviteCreateOptions](/reference/options#invitecreateoptions). Which channels can create one is in [Channels](/reference/channels).
</Note>

## Properties

<ResponseField name="inviter" type="User | null">
  Who created the invite, when Discord says it.
</ResponseField>

<ResponseField name="code" type="string">
  The unique code of the invite (`discord.gg/code`).
</ResponseField>

<ResponseField name="url" type="string">
  The link to share.
</ResponseField>

<ResponseField name="guildId" type="Snowflake | null">
  The id of the server the invite leads to.
</ResponseField>

<ResponseField name="channelId" type="Snowflake | null">
  The id of the channel the invite leads to.
</ResponseField>

<ResponseField name="expiresAt" type="Date | null">
  When the invite stops working; `null` when it never does.
</ResponseField>

<ResponseField name="uses" type="number | null">
  How many times the invite was used, when Discord says it.
</ResponseField>

<ResponseField name="maxUses" type="number | null">
  How many times the invite can be used; `0` means no limit.
</ResponseField>

<ResponseField name="temporary" type="boolean">
  Whether members who joined with it are kicked when they go offline.
</ResponseField>

<Info>
  An invite has no `id` and no `createdAt`: Discord identifies it by its `code`.
</Info>

## Helpers

These read what the bot remembers: they never send a request.

### toString()

```ts
toString(): string
```

The link to share.

### toJSON()

```ts
toJSON(): object
```

The data of Discord as a plain object, with camelCase names.

## Actions

### delete()

```ts
delete(reason?: string): Promise<void>
```

Deletes the invite: its link stops working.

[Discord documentation](https://docs.discord.com/developers/resources/invite#delete-invite)
