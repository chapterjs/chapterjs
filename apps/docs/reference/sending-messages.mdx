`channel.send()`, `message.reply()`, `user.send()`, `member.send()` and `webhook.send()` all take the same thing: a text, or an object of options.

```ts
import type { TextChannel } from 'chapterjs';

async function example(channel: TextChannel) {
  // A text...
  await channel.send('Hello!');

  // ...or options.
  await channel.send({
    content: 'Here is the report',
    embeds: [
      {
        title: 'Weekly report',
        description: 'Everything went well.',
        color: 0x5865f2,
        fields: [
          { name: 'New members', value: '42', inline: true },
          { name: 'Messages', value: '1 337', inline: true },
        ],
        footer: { text: 'Generated automatically' },
        timestamp: new Date().toISOString(),
      },
    ],
    files: [{ name: 'report.txt', data: 'The full report', description: 'The report as a file' }],
    silent: true,
  });
}
```

## MessageOptions

A `?` after a name means the field can be left out.

| Field | Type | Description |
| --- | --- | --- |
| `content?` | `string` | The text of the message (up to 2000 characters). |
| `embeds?` | `Embed[]` | Up to 10 embeds. |
| `components?` | `Component[]` | Buttons, select menus and layout components. |
| `files?` | `FileInput[]` | Up to 10 files to attach. |
| `allowedMentions?` | `AllowedMentions` | Who the message is allowed to notify. |
| `stickers?` | `Snowflake[]` | The ids of up to 3 stickers of the server. |
| `poll?` | `PollInput` | A poll to attach to the message. |
| `tts?` | `boolean` | Reads the message aloud. |
| `silent?` | `boolean` | Sends the message without a notification sound. |
| `suppressEmbeds?` | `boolean` | Does not show the previews of the links of the message. |
| `replyTo?` | `Snowflake \| { id: Snowflake }` | The message to reply to. |


A message needs at least a content, an embed, a file, a component, a sticker or a poll.

### Editing

`message.edit()` accepts a text, or `content`, `embeds`, `components`, `files`, `allowedMentions` and `suppressEmbeds`. Only what you pass changes: pass an empty list to remove embeds, for example.

## Files

A `?` after a name means the field can be left out.

A file to attach to a message.

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | The name of the file, with its extension: `chart.png`. |
| `data` | `Blob \| Uint8Array \| ArrayBuffer \| string` | The content of the file. |
| `description?` | `string` | What the file shows, for people who can't see it. |
| `spoiler?` | `boolean` | Hides the file until it is clicked. |
| `contentType?` | `string` | The media type of the file (`image/png`); guessed from the name when missing. |


```ts
import { readFile } from 'node:fs/promises';
import type { TextChannel } from 'chapterjs';

async function sendImage(channel: TextChannel) {
  await channel.send({
    files: [{ name: 'chart.png', data: await readFile('./chart.png') }],
    // An embed can show an attached image.
    embeds: [{ title: 'This week', image: { url: 'attachment://chart.png' } }],
  });
}
```

## Embeds

### Embed

A `?` after a name means the field can be left out.

| Field | Type | Description |
| --- | --- | --- |
| `title?` | `string` | Title of embed |
| `description?` | `string` | Description of embed |
| `url?` | `string` | Url of embed |
| `timestamp?` | `ISO8601Timestamp` | Timestamp of embed content |
| `color?` | `number` | Color code of the embed |
| `footer?` | `EmbedFooter` | Footer information |
| `image?` | `EmbedImage` | Image information |
| `thumbnail?` | `EmbedImage` | Thumbnail information |
| `author?` | `EmbedAuthor` | Author information |
| `fields?` | `EmbedField[]` | Fields information, max of 25 |

[Discord documentation](https://docs.discord.com/developers/resources/message#embed-object-embed-structure)

### footer

| Field | Type | Description |
| --- | --- | --- |
| `text` | `string` | Footer text |
| `iconUrl?` | `string` | Url of footer icon (only supports http(s) and attachments) |
| `proxyIconUrl?` | `string` | A proxied url of footer icon |

[Discord documentation](https://docs.discord.com/developers/resources/message#embed-object-embed-footer-structure)

### author

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Name of author |
| `url?` | `string` | Url of author (only supports http(s)) |
| `iconUrl?` | `string` | Url of author icon (only supports http(s) and attachments) |
| `proxyIconUrl?` | `string` | A proxied url of author icon |

[Discord documentation](https://docs.discord.com/developers/resources/message#embed-object-embed-author-structure)

### fields

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Name of the field |
| `value` | `string` | Value of the field |
| `inline?` | `boolean` | Whether or not this field should display inline |

[Discord documentation](https://docs.discord.com/developers/resources/message#embed-object-embed-field-structure)

### image and thumbnail

Only `url` is yours to set: Discord fills the rest when it sends a message back.

| Field | Type | Description |
| --- | --- | --- |
| `url` | `string` | Source url of image (only supports http(s) and attachments) |
| `description?` | `string` | Description (alt text) for the image |

[Discord documentation](https://docs.discord.com/developers/resources/message#embed-object-embed-image-structure)


| Limit | Maximum |
| --- | --- |
| Embeds per message | 10 |
| `title` | 256 characters |
| `description` | 4096 characters |
| `fields` | 25 |
| `fields[].name` | 256 characters |
| `fields[].value` | 1024 characters |
| `footer.text` | 2048 characters |
| `author.name` | 256 characters |
| All of the above, for every embed of a message | 6000 characters |

Going over a limit throws an error that names the field, before anything is sent.

## Who gets notified

By default a message notifies everyone it mentions. `allowedMentions` restricts that:

### AllowedMentions

| Field | Type | Description |
| --- | --- | --- |
| `parse?` | `AllowedMentionType[]` | An array of allowed mention types to parse from the content |
| `roles?` | `Snowflake[]` | Array of role ids to mention, max 100 |
| `users?` | `Snowflake[]` | Array of user ids to mention, max 100 |
| `repliedUser?` | `boolean` | For replies, whether to mention the author of the message being replied to, defaults to false |

[Discord documentation](https://docs.discord.com/developers/resources/message#allowed-mentions-object-default-settings-for-allowed-mentions)


```ts
import type { Message } from 'chapterjs';

async function quote(message: Message) {
  // Repeats what someone wrote without pinging anyone.
  await message.reply({
    content: message.content,
    allowedMentions: { parse: [], repliedUser: false },
  });
}
```

## Polls

### PollInput

| Field | Type | Description |
| --- | --- | --- |
| `question` | `PollMedia` | The question of the poll. Only `text` is supported. |
| `answers` | `PollAnswer[]` | Each of the answers available in the poll, up to 10 |
| `duration?` | `number` | Number of hours the poll should be open for, up to 32 days. Defaults to 24 |
| `allowMultiselect?` | `boolean` | Whether a user can select multiple answers. Defaults to false |
| `layoutType?` | `PollLayoutType` | The layout type of the poll. Defaults to... DEFAULT! |

[Discord documentation](https://docs.discord.com/developers/resources/poll#poll-create-request-object-poll-create-request-object-structure)

### question and pollMedia

| Field | Type | Description |
| --- | --- | --- |
| `text?` | `string` | The text of the field |
| `emoji?` | `Partial<Emoji>` | The emoji of the field |

[Discord documentation](https://docs.discord.com/developers/resources/poll#poll-media-object-poll-media-object-structure)


```ts
import type { TextChannel } from 'chapterjs';

async function ask(channel: TextChannel) {
  await channel.send({
    poll: {
      question: { text: 'Pizza or pasta?' },
      answers: [
        { answerId: 1, pollMedia: { text: 'Pizza', emoji: { name: '🍕' } } },
        { answerId: 2, pollMedia: { text: 'Pasta', emoji: { name: '🍝' } } },
      ],
      duration: 24, // hours
    },
  });
}
```

## Components

`components` takes the components of the [Discord component reference](https://docs.discord.com/developers/components/reference), with camelCase names. Use `ComponentType` and `ButtonStyle` instead of numbers:

```ts
import { ButtonStyle, ComponentType, type TextChannel } from 'chapterjs';

async function withButtons(channel: TextChannel) {
  await channel.send({
    content: 'Do you accept the rules?',
    components: [
      {
        type: ComponentType.ActionRow,
        components: [
          { type: ComponentType.Button, style: ButtonStyle.Success, label: 'Accept', customId: 'rules:accept' },
          { type: ComponentType.Button, style: ButtonStyle.Link, label: 'Read them', url: 'https://example.com/rules' },
        ],
      },
    ],
  });
}
```

## Webhooks

`webhook.send()` accepts the same options (except `replyTo`), plus:

| Field | Type | Description |
| --- | --- | --- |
| `username?` | `string` | Shows this name instead of the name of the webhook. |
| `avatarURL?` | `string` | Shows this avatar instead of the avatar of the webhook. |
| `threadId?` | `Snowflake` | Sends the message in this thread of the channel of the webhook. |
