The `components` of a message take pieces made by ChapterJS: the files of `src/components/`, and the helpers of this page, imported from `'chapterjs'`. Each is checked against the limits of Discord when it is made.

```ts
import { container, separator, text, type GuildMember, type TextChannel } from 'chapterjs';

async function profile(channel: TextChannel, member: GuildMember) {
  await channel.send({
    components: [container([text(`## ${member.displayName}`), separator(), text(`${member.roles.length} roles`)], { color: 0xc026d3 })],
  });
}
```

<Note>
  How to build a message out of these is in [Embeds and layout](/components/embeds).
</Note>

## Helpers

### row()

```ts
row(components: readonly (ButtonComponent | SelectComponent)[]): ActionRowComponent
```

A row of components: up to 5 buttons, or one select menu. The framework makes rows by itself; use this to choose which buttons share a row.

[Discord documentation](https://docs.discord.com/developers/components/reference#action-row)

### linkButton()

```ts
linkButton(options: LinkButtonOptions): ButtonComponent
```

A button that opens a link. Nothing runs in your bot when it is clicked: Discord opens the address.

[Discord documentation](https://docs.discord.com/developers/components/reference#button)

### premiumButton()

```ts
premiumButton(skuId: Snowflake, options?: { disabled?: boolean }): ButtonComponent
```

A button that offers something to buy: Discord shows the name and the price of the SKU itself.

[Discord documentation](https://docs.discord.com/developers/components/reference#button)

### text()

```ts
text(content: string): TextComponent
```

A text in a message built with components. Markdown works as in any message, mentions included. The texts of a message add up to 4000 characters at most.

[Discord documentation](https://docs.discord.com/developers/components/reference#text-display)

### section()

```ts
section(texts: string | readonly string[], accessory: ButtonComponent | ThumbnailComponent): SectionComponent
```

One to three texts with a button or a thumbnail beside them.

[Discord documentation](https://docs.discord.com/developers/components/reference#section)

### thumbnail()

```ts
thumbnail(media: string | MediaOptions): ThumbnailComponent
```

A small picture beside the texts of a section.

[Discord documentation](https://docs.discord.com/developers/components/reference#thumbnail)

### gallery()

```ts
gallery(items: readonly (string | MediaOptions)[]): GalleryComponent
```

Up to 10 pictures or videos, shown in a grid.

[Discord documentation](https://docs.discord.com/developers/components/reference#media-gallery)

### file()

```ts
file(name: string, options?: { spoiler?: boolean }): FileComponent
```

A file sent with the message (its `files`), shown where it is placed.

[Discord documentation](https://docs.discord.com/developers/components/reference#file)

### separator()

```ts
separator(options?: SeparatorOptions): SeparatorComponent
```

Space between two pieces, with a line by default.

[Discord documentation](https://docs.discord.com/developers/components/reference#separator)

### container()

```ts
container(children: readonly ContainerChild[], options?: ContainerOptions): ContainerComponent
```

A box around texts, sections, rows, galleries, files and separators, with an optional color on its left, like an embed.

[Discord documentation](https://docs.discord.com/developers/components/reference#container)

## Options

### LinkButtonOptions

A link button: what it shows, and the address it opens.

<ResponseField name="url" type="string" required>
  The address the button opens (512 characters at most).
</ResponseField>

<ResponseField name="label" type="string">
  The text on the button (80 characters at most).
</ResponseField>

<ResponseField name="emoji" type="EmojiInput">
  An emoji on the button, before the label.
</ResponseField>

<ResponseField name="disabled" type="boolean">
  Shows the button greyed out, impossible to click.
</ResponseField>

### MediaOptions

A picture or a video: its address, or `attachment://name` for a file of the message.

<ResponseField name="url" type="string" required>
  The address of the media: a link, or `attachment://chart.png` for a file sent with the message.
</ResponseField>

<ResponseField name="description" type="string">
  What the media shows, for people who can't see it (1024 characters at most).
</ResponseField>

<ResponseField name="spoiler" type="boolean">
  Blurs the media until it is clicked.
</ResponseField>

### SeparatorOptions

How a separator looks.

<ResponseField name="divider" type="boolean">
  Shows a line. Shown by default.
</ResponseField>

<ResponseField name="spacing" type="'small' | 'large'">
  How much space: `'small'` (the default) or `'large'`.
</ResponseField>

### ContainerOptions

How a container looks.

<ResponseField name="color" type="number">
  The color of the line on its left, as a number (`0xc026d3`).
</ResponseField>

<ResponseField name="spoiler" type="boolean">
  Blurs the whole container until it is clicked.
</ResponseField>

## The pieces

### MessageComponent

```ts
type MessageComponent = ContainerChild | ContainerComponent
```

What the `components` of a message take. Buttons and menus are put in rows by the framework (5 buttons per row, a menu alone in its row); `row()` is there to choose. As soon as a message has a text, a section, a gallery, a file, a separator or a container, it is built with components only: Discord then takes no `content` and no `embeds`.

### ContainerChild

```ts
type ContainerChild = ButtonComponent | SelectComponent | ActionRowComponent | TextComponent | SectionComponent | GalleryComponent | FileComponent | SeparatorComponent
```

What a container can hold.

### Piece

```ts
interface Piece<Kind extends string> { readonly [brand]: Kind }
```

A piece of a message made by ChapterJS: a button, a menu, a layout. Only the framework makes pieces: a plain object is refused where a piece is expected, with a message that says what to use instead. Every piece is a `Piece`:

| Type | Made by |
| --- | --- |
| `ButtonComponent` | A file of `src/components/buttons/`, `linkButton()`, `premiumButton()` |
| `SelectComponent` | A file of `src/components/selects/` |
| `ModalComponent` | A file of `src/components/modals/`, for `interaction.showModal()` |
| `ActionRowComponent` | `row()` |
| `TextComponent` | `text()` |
| `SectionComponent` | `section()` |
| `ThumbnailComponent` | `thumbnail()` |
| `GalleryComponent` | `gallery()` |
| `FileComponent` | `file()` |
| `SeparatorComponent` | `separator()` |
| `ContainerComponent` | `container()` |

[Discord documentation](https://docs.discord.com/developers/components/reference)
