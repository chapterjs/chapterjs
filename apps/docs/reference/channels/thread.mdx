title: 'ThreadChannel'
description: 'A thread or a forum post: archive, lock, members and tags'

A `ThreadChannel` is a thread, or a post of a forum. It is what `channel.isThread()` gives, and what `message.startThread()`, `channel.startThread()` and `forum.createPost()` return.

```ts
import type { ThreadChannel } from 'chapterjs';

async function close(thread: ThreadChannel, reason: string) {
  if (thread.archived) return;
  await thread.send(`Closing this thread: ${reason}`);
  await thread.edit({ archived: true, locked: true }, reason);
}
```

<Note>
  How to send, edit and read messages is in [Sending messages](/messages).
</Note>

## Properties

It also has everything of [Channel](/reference/channels#channel) and [what channels with messages share](/reference/channels#channels-with-messages). A thread is not a `GuildChannel`: it has no overwrites of its own, and takes the permissions of the channel it is in.

  The id of the server of the thread.
</ResponseField>

<ResponseField name="guild" type="Guild">
  The server of the thread.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the thread.
</ResponseField>

<ResponseField name="parentId" type="Snowflake">
  The id of the channel the thread was created in.
</ResponseField>

<ResponseField name="parent" type="TextChannel | ForumChannel | null">
  The channel the thread was created in; `null` when it is of a kind this version does not know.
</ResponseField>

<ResponseField name="ownerId" type="Snowflake | null">
  The id of the user who created the thread.
</ResponseField>

<ResponseField name="archived" type="boolean">
  Whether the thread is archived.
</ResponseField>

<ResponseField name="locked" type="boolean">
  Whether only moderators can unarchive it.
</ResponseField>

<ResponseField name="isPrivate" type="boolean">
  Whether only invited members and moderators can see it.
</ResponseField>

<ResponseField name="archivedAt" type="Date | null">
  When the thread was archived or unarchived for the last time.
</ResponseField>

<ResponseField name="memberCount" type="number">
  An approximate count of the members of the thread (stops at 50).
</ResponseField>

<ResponseField name="appliedTags" type="readonly Snowflake[]">
  The ids of the tags of the post, in a forum.
</ResponseField>

## Helpers

### permissionsFor()

```ts
permissionsFor(member: GuildMember): Permissions
```

Threads inherit the permissions of the channel they are in.

## Reading from Discord

### fetchMembers()

```ts
fetchMembers(options?: { limit?: number; after?: Snowflake }): Promise<ThreadMember[]>
```

Who is in the thread (100 at most per call). Each entry is a [`ThreadMember`](/reference/data#threadmember).

[Discord documentation](https://docs.discord.com/developers/resources/channel#list-thread-members)

## Actions

### edit()

```ts
edit(options: ThreadEditOptions, reason?: string): Promise<this>
```

Changes the thread: name, archive, lock, slowmode, tags. The options are a [`ThreadEditOptions`](/reference/options#threadeditoptions).

[Discord documentation](https://docs.discord.com/developers/resources/channel#modify-channel)

### archive()

```ts
archive(reason?: string): Promise<this>
```

Archives the thread: it leaves the channel list but can come back.

[Discord documentation](https://docs.discord.com/developers/resources/channel#modify-channel)

### unarchive()

```ts
unarchive(reason?: string): Promise<this>
```

Brings an archived thread back.

[Discord documentation](https://docs.discord.com/developers/resources/channel#modify-channel)

### join()

```ts
join(): Promise<void>
```

Makes the bot join the thread.

[Discord documentation](https://docs.discord.com/developers/resources/channel#join-thread)

### leave()

```ts
leave(): Promise<void>
```

Makes the bot leave the thread.

[Discord documentation](https://docs.discord.com/developers/resources/channel#leave-thread)

### addMember()

```ts
addMember(user: Snowflake | { id: Snowflake }): Promise<void>
```

Adds a member to the thread.

[Discord documentation](https://docs.discord.com/developers/resources/channel#add-thread-member)

### removeMember()

```ts
removeMember(user: Snowflake | { id: Snowflake }): Promise<void>
```

Removes a member from the thread.

[Discord documentation](https://docs.discord.com/developers/resources/channel#remove-thread-member)
