# create-chapterjs

An alias of [`create-chapter`](https://www.npmjs.com/package/create-chapter), so that both spellings create a [ChapterJS](https://www.chapterjs.org) Discord bot:

```bash
pnpm create chapterjs my-bot
```

```bash
pnpm create chapter my-bot
```

Same questions, same templates, same version: this package only runs `create-chapter` with the arguments it receives. See [its README](https://www.npmjs.com/package/create-chapter) and the [quickstart](https://www.chapterjs.org/quickstart).
