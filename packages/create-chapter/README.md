# create-chapter

An alias of [`create-chapterjs`](https://www.npmjs.com/package/create-chapterjs), so that both spellings create a [ChapterJS](https://www.chapterjs.org) Discord bot:

```bash
pnpm create chapter my-bot
```

```bash
pnpm create chapterjs my-bot
```

Same questions, same templates, same version: this package only runs `create-chapterjs` with the arguments it receives. See [its README](https://www.npmjs.com/package/create-chapterjs) and the [quickstart](https://www.chapterjs.org/quickstart).
